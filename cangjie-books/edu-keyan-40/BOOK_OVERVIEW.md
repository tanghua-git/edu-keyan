## 1. 结构 (Structural)

### 类型
实操手册 / 方法论——面向一线教师的课题研究全流程操作指南，以 40 个问答组织，每个问题配 1—3 个实名立项课题实例。

### 一句话主旨
一线教师做课题研究，就是按"选题 → 方案设计 → 过程实施 → 方法运用 → 成果总结"五个阶段，"想好了做研究"，用科学规范的行动解决自身真实的教育教学问题，并在过程中实现专业成长。

### 骨架 (主要论点及其关系)
1. **选题是定向**：课题源于问题，选题两维度（应然/实然矛盾、整体/局部关联）+ 四来源（自身实践、改革热点、经典理论、他人经验）+ 名称表述规范。（第一章，问题1—8）
2. **研究需要设计**：方案核心讲清三件事——研究什么、怎样研究、预期效果；七要素（提出/综述/界定/目标/内容/路径/策略）环环相扣。（第二章，问题9—16）
3. **过程质量决定成果质量**：研究活动分"学习—领会"与"实践—反思"两类，靠工具、计划、子课题、分享让成员深度参与，过程性资料分四类及时积累，阶段性成果及时提炼发布。（第三章，问题17—24）
4. **方法体现科学审慎**：行动研究为总范式，调查/课例/叙事/个案/实验/文献/微调查各有适用域，走出"行动研究不要计划"的误区。（第四章，问题25—32）
5. **成果需要总结与推广**：报告三层次要素（基本/核心/增色），成效按策略/对象/研究者三维度表达，图表附件答辩推广各有章法。（第五章，问题33—40）

**论点之间的关系**: 递进（严格按课题生命周期的时间流程展开），第一章是起点，二、五章是文本产出端，三、四章是过程保障端。自序以作者"自发研究→自觉研究→系统研究"三阶段经历论证"研中明—明中得—得中立—立中成"的成长价值链。

### 作者要解决的核心问题
一线教师"不会做课题"的五个断点：选不出题（问题变不成课题）、写不好方案（空泛无逻辑）、做不实过程（挂名、无资料）、用不对方法（行动研究=随意做）、写不出成果（有资料没报告）。

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 问题 vs 课题 | 问题是客观存在的现象；课题是主观关注、主动探索的产物，是"一种假设，一种亟待验证的解决问题的方法" | 教师常把问题直接当课题（如"如何培养小班幼儿规则意识"），缺假设、研究点不明 |
| 应然 / 实然 | 应然=理论导向与政策导向决定的"应该的样子"；实然=实际存在的样子；两者矛盾即选题着眼点 | 不是哲学讨论，是选题的操作性工具 |
| 行动研究 | "想好了做研究"——有计划、有思路、有方法、有提炼，进程可随情境调整但研究目的不变 | 针对一线误区：行动研究≠无须方案、可随时放弃计划 |
| 本体/对象/主体目标 | 本体目标=研究本身要产出的策略方法（必写）；对象目标=研究对象（学生/教师/课程）的变化（必写）；主体目标=研究者自身变化（可选） | 不是笼统的"研究目标"，三个维度可检验、防泛化窄化 |
| 研究路径 vs 工作程序 | 研究路径=基于内容逻辑的深入研究思路（理论→实践 / 并举 / 问题归因—实践解决三型）；工作程序=阶段、分工、时间表 | 一线方案常把工作程序冒充研究路径 |
| 形而上 / 形而下 | 已有成果基础上深入研究的两个方向：理论建构深化（适合名师）/ 实践路径细化（适合一线） | 借哲学词作选题策略分类，非哲学义 |
| 微型课题 | 小切口、个人可申报的课题，主线是"问题呈现→成效验证" | 嘉兴市 2007 年起的制度设计，书中作为一线入门推荐形态 |
| 微调查 | 围绕一节课/一个知识点的小范围简易调查（前测—教学—后测），突出实用性 | 区别于规范调查研究：范围小、手段简、分析快 |
| 数概括 / 关键词前提 | 课题名称创新表述结构："三化两制""成长驿站：……"式 | 作者提醒慎用——表意不清时不如常规结构 |
| 过程性资料四类 | 文献政策类 / 理性思考类 / 实践案例类 / 数据分析类 | 不是"什么材料都留着"，而是按研究逻辑分类积累 |

### 核心命题 (用自己的话)
1. 选题的本质是在应然与实然的矛盾中、在整体与局部的关联中找到有价值、可聚焦、能操作的研究点。
2. 问题变课题要过四关：专业内涵剖析、内外价值判断、可行性聚焦（小处着手）、逻辑结构细化（分解子问题）。
3. 课题名称要把"研究什么、怎样研究"第一时间讲清楚：概念准确、变量逻辑清晰、有自身特色，创新表述必须服从这一基本原则。
4. 研究方案万变不离三问：研究什么（起点）、怎样研究（关键）、预期效果（基于假设的验证）。
5. 研究综述必须"综而述之、述而评之"，有分评有总评，最终落点是明晰自己课题的突破点；资料遵循"四用四不用"。
6. 课题界定=核心概念界定（本义→特指义，或内涵+外延）+研究范围界定，是方案的逻辑起点。
7. 研究目标按本体/对象/主体三维度写，越具体越好，它是后续成效分析的对照依据。
8. 研究路径只有三种基本型：理论到实践（热点/理论类选题）、理论与实践并举（课程开发类）、问题归因—实践解决（实践问题/微型课题类）。
9. 操作策略要"适度具体"：图表式呈现流程、"动词"细化要点（如"解—引—议""仿—磨—悟"），给行动研究留自主探索空间。
10. 研究实践活动区别于日常教学的标志：有假设、有分析、有提炼、有资料物化——突出"研究味儿"。
11. 让成员深度参与靠机制不靠觉悟：工具引导、计划分工、子课题认领（纵向递进/横向并列）、阶段性分享。
12. 阶段性成果要"边做边提炼"：观点论文与案例分析两种基本样式，发表/会议/展示三种发布途径，它同时服务于问题思辨、效果审思、预期成果与团队激励。
13. 一线教师以行动研究为总范式，但必须走出"行动研究不要计划"的误区：研究随情境、思路须明确；过程重实践、方法须科学；目标可调整、目的不改变；研究出结论、策略有提炼。
14. 方法选择有适用域：课例研究适合课堂主题（个体用前测四环节、群体用多轮行为跟进）；叙事研究重"讲故事+析原理"；个案研究"有典型性、不具代表性"；实验研究一线只做确认性实验与准实验；文献研究是选题与综述的基本功；微调查让课堂教学从经验走向实证。
15. 课题研究报告是把"问题—归因—假设—实施—分析—结论"的解决过程记录成文；好报告=实践的体验+逻辑的思考+创新的元素。
16. 成效表述必须对照研究目标，按策略（结构化提炼）/对象（定性+定量）/研究者（侧面补充）三维度呈现，"课题组教师研究能力提高了"这类空话不说也罢。
17. 成果影响力是做出来的也是推出来的：扎实做研究是根本，善总结、巧宣传、真推广是路径。

### 论证链
作者用三重证据支撑每个方法论点：(1) 自身近 30 年科研经历（从 1995 年第一个课题到省级重点课题、专著出版）；(2) 大量浙江省市级实名立项课题的完整案例（每个问题 1—3 个，含立项编号）；(3) 教育研究方法经典著作（裴娣娜、陈向明、李冲锋、冯卫东等）的理论引证。论证路径基本是"观点 → 反例（一线常见问题）→ 正例（实名课题）→ 操作要点提炼"。

## 3. 批判 (Critical) ★

### 作者的时代局限
- 成书于"核心素养"落地初期（案例集中 2010—2018 年），热点案例（微课、电子书包、STEM、"区块链+"）部分已过气，热点判断不能直接迁移到今天的 AI+教育语境。
- 全书未涉及 AI 工具对科研流程的改变（文献检索、问卷分析、文本写作），"电子档案库"等信息化表述停留在文件夹/网络平台思维。
- 课题管理制度话语（教科规划条线、教研条线、微型课题）以浙江省、特别是嘉兴市为样本，其他省市的申报格式与评审口径有差异。

### 作者的立场盲点
- 作者是发达地区（浙江嘉兴）的小学数学教研员，案例集中于小学数学、幼教与区域课题，对农村薄弱学校、初高中其他学科、无教研支持环境的教师覆盖不足。
- 默认教师做课题有区域科研管理系统托底（记载册、结题要求、成果评审体系），对"一个人在一所学校单干"的情形着墨少。
- 对功利性做课题（为职称、为考核）导致的形式主义只有零星批评，未作正面讨论。

### 未被证明的假设
- "做课题必然促进教师专业成长"——作者以自身成功案例论证，缺乏对失败/中途放弃课题的分析。
- "行动研究的结论可以为同伴所用"——质性研究结论的可迁移性被默认，未深入讨论边界。
- "把过程做扎实，成果自然好"——过程扎实与成果质量的因果链是经验断言。

### 最强反对意见
一线教师工作负担已重，书中理想化要求（研究简报、档案袋、多轮磨课、子课题群）在缺乏时间与团队支持的学校难以落地，照单全收反而制造新的形式主义；且全书方法论属经验归纳，缺少方法论训练的教师容易"形似而神不似"。
