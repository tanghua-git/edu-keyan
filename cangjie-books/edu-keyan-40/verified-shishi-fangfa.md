## 二、通过的 methodology 单元（V1∧V2∧V3 全过）

### v-sh-01 研究味儿四标志（课题研究区别于日常教学）
- type: principle
- 合并来源: p51, ce23
- V1_cross_domain: passed true
  - 证据：①第三章问题17（原书 p39-73）正面立论"课题研究最基本的特征是研究，需要突出'研究味儿'"，给出四标志；②反面佐证 ce23"课题研究缺乏研究味（混同日常教学）"；③案例 c29（林云娣新媒体作业课题）以"有围绕主题的假设、有依据假设的分析"作正面范例。
- V2_predictive_power: passed true
  - novel_question：某教研组把一学期的公开课直接当作"课题"，要不要提醒他们这不算研究？
  - derived_answer：用四标志审——若公开课只有"上课"没有"围绕主题的假设"、课后只有评课没有"依据假设的分析与规律提炼"、无过程资料物化，则属日常教学而非课题研究，应补设假设与反思分析环节。
- V3_exclusivity: passed true
  - why_not_common：作者自创"研究味儿"概念并把"研究 vs 教学"的边界操作化为四个可检核标志（假设/分析/提炼/资料物化），不是泛泛"要认真做研究"，而是给出了辨别研究真伪的具体判据。
- → 进入阶段 2

### v-sh-02 过程性资料四类（文献政策 / 理性思考 / 实践案例 / 数据分析）
- type: framework
- 合并来源: f32, p61, p62, p63, t19, c33
- V1_cross_domain: passed true
  - 证据：①问题21（原书 p114-119）立"四类"总框架；②p389 再分"理性思考类=问题思考+概念思辨"；③p402 再分"实践案例类=量表设计+案例分析"；④案例 c33（马茂霞668名学生调查）是"数据分析类"的实证范例。
- V2_predictive_power: passed true
  - novel_question：一个 5 人课题组分布在 3 所学校，开学初该优先建哪类资料库？
  - derived_answer：按四类分别建——文献政策类（统一检索的政策/理论基线，供三校共享）、理性思考类（各校问题归因与概念思辨）、实践案例类（各校量表与课例）、数据分析类（前后测数据）。可推：跨校课题最易缺"文献政策类"统一基线，应最先建共享库，避免三校各说各话。
- V3_exclusivity: passed true
  - why_not_common：普通做法是"什么都留着"或只留教案。作者把过程资料按"文献政策/理性思考/实践案例/数据分析"四向分类，并把"理性思考"再拆为问题思考与概念思辨——这个分类的结构本身有分析洞见（区分了"材料"与"思考"），非常识罗列。
- → 进入阶段 2

### v-sh-03 阶段性成果及时提炼四意义（边做边提炼）
- type: framework
- 合并来源: f34, p67, ce25, c30
- V1_cross_domain: passed true
  - 证据：①问题23（原书 p124-129）正面立"四意义"；②反面 ce25"忽视阶段性成果及时提炼"；③案例 c30（林云娣新闻微评论）以"基于调查数据的深度归因"示范"深度思辨研究问题"。
- V2_predictive_power: passed true
  - novel_question：课题组临结题才想起没写过东西，现在补来得及吗？
  - derived_answer：用四意义推——此时已丧失"审思阶段效果"（无法中途调策略）、丧失"激发人员动力"（成员无成就感）、且"完成预期成果"变成仓促拼凑。结论：应回溯过程资料立刻补写观点论文/案例分析，但"审思效果"价值已无法追回，下次须把提炼设为节奏。
- V3_exclusivity: passed true
  - why_not_common：一般建议是"及时总结"，作者给出四个非同质的理由，尤其"激发研究人员动力"把"边写边提炼"定位为团队管理手段而非单纯的文本工作，这是对"为什么要中途写"的反直觉回答。
- → 进入阶段 2

### v-sh-04 成员深度参与四机制 / 子课题两式（靠机制不靠觉悟）
- type: framework
- 合并来源: f30, f31, p57, p59, t18, c16, ce24
- V1_cross_domain: passed true
  - 证据：①问题20（原书 p109-114）立"四机制"与"子课题两式"；②反面 ce24"课题成员挂名（参与不深）"；③案例 c16（林乐珍助学稿子课题群）同时示范纵向递进+横向并列两式。
- V2_predictive_power: passed true
  - novel_question：10 人课题，3 个骨干做、7 个挂名，如何破？
  - derived_answer：套四机制——用"工具"（观察/记录表让挂名者被迫卷入）、"计划"（纳入分工与时间节点）、"子课题认领"（把主课题拆成 7 个小题让每人认领，按纵向递进或横向并列组织）、"阶段性分享"（强制汇报）。可推：挂名问题的解药是结构设计而非思想动员。
- V3_exclusivity: passed true
  - why_not_common：核心洞见是"靠机制不靠觉悟"——用工具/子课题/分享等结构性安排解决参与问题，而非靠号召。一个外行聪明人未必能想到"用子课题群+纵向/横向拆分"来化解挂名，这是作者特有的组织方法论。
- → 进入阶段 2

### v-sh-05 电子档案库四优势（2019 语境下的前瞻性）
- type: checklist
- 合并来源: p65
- V1_cross_domain: passed true
  - 证据：①问题22（原书 p465）专论"电子档案库"并对比"电子档案袋"；②同节 p461 论"档案袋须归类、编码、总结"作为对照语境。
- V2_predictive_power: passed true
  - novel_question：2025 年一个跨校课题组用什么资料系统最稳？
  - derived_answer：用四优势推——便捷（云收集文献）、即时（成员随时上传共享，对应异地协作）、可控（组内/组外互动可限定）、长效（不删即永久）。可推：这正是当前云端协作档案的雏形，作者的 2019 预判在疫情后远程协作中完全成立。
- V3_exclusivity: passed true
  - why_not_common：在 2019 年语境下，把"电子档案库"与"电子档案袋（文件夹思维）"区分，并提出"便捷/即时/可控/长效"四优势，具有明显的前瞻性（预判了在线协作档案），不是对"用电脑存资料"的老生常谈。
- → 进入阶段 2

### v-sh-06 策略动词化表达（用三动词概括操作要点）
- type: framework（由案例 c23 提升）
- 合并来源: c23（唐燕迎区域联动教研：解-引-议 / 仿-磨-悟）
- V1_cross_domain: passed true
  - 证据：①问题16（原书 p612-636）以"引领式（解-引-议）/助推式（仿-磨-悟）"示范；②同章多处强调策略要"可操作、可理解"，动词化是其手法之一。
- V2_predictive_power: passed true
  - novel_question：团队写出的策略全是"加强……培养……提升……"虚词，怎么落地？
  - derived_answer：用动词化推——给每条策略找 3 个动作动词构成操作链（如"解-引-议"），让执行者一看就知道第一步做什么、第二步做什么，把形容词式策略转成动作序列。
- V3_exclusivity: passed true
  - why_not_common：作者把"用三个动词概括一种模式的操作要点并逐一解释"作为让策略可操作、可理解的专门技术，这是写作/表达层面的 craft 洞见，普通教师只会写"要重视……"。
- → 进入阶段 2

### v-fa-01 行动研究四要点（情境思路 / 实践方法 / 目标目的 / 结论提炼）
- type: framework
- 合并来源: f37, ce26, c43
- V1_cross_domain: passed true
  - 证据：①问题25（原书 p137-146）立"四要点"走出"行动研究=随意做"误区；②反面 ce26"对行动研究的误解（无须计划）"；③案例 c43（L老师生问生答）完整演示四要点。
- V2_predictive_power: passed true
  - novel_question：研究中途发现原假设不对，能不能直接换方向？
  - derived_answer：用"目标可调整、目的不改变"推——可调整具体目标与研究路径，但研究目的（要解决的真问题）不能变；同时须"研究出结论、策略有提炼"。可推：换方向≠放弃计划，须保留原目的并补做提炼。
- V3_exclusivity: passed true
  - why_not_common：反直觉地把"行动研究"与"随意做"解绑，并给出"目的不变、目标可调"的张力处理，这是书中最核心的范式澄清，外行容易误读行动研究为"边做边改不用想"。
- → 进入阶段 2

### v-fa-02 调查四作用（发现聚焦问题 / 印证假设 / 采集数据 / 体验科学方法）
- type: framework
- 合并来源: f39, t21, c44, c45, c33
- V1_cross_domain: passed true
  - 证据：①问题27（原书 p147-159）立"四作用"；②案例 c44（大班餐前游戏，问卷+访谈+观察）示范"发现聚焦问题"；③案例 c45（学前识字"零起点"印证）示范"调查印证问题"；④案例 c33 示范"采集数据"。
- V2_predictive_power: passed true
  - novel_question：小课题不想发大问卷，还能用调查吗？
  - derived_answer：用四作用推——调查不只是"发问卷采集大数据"，更常用来"发现/印证一个小问题"（如 c45 用 265 人测试印证"非真零起点"）。可推：一线应多做嵌入式小调查，而非为大调查而调查。
- V3_exclusivity: passed true
  - why_not_common：把"体验科学方法"列为调查的第四种作用，并指出调查可"嵌入课题、为结论提供实证"而非独立宏大工程，矫正了"调查=写大问卷交差"的常识误解。
- → 进入阶段 2

### v-fa-03 课例研究两范式（基于前测四环节 / 指向共生多轮跟进）
- type: framework
- 合并来源: f40, t22, c08, c46
- V1_cross_domain: passed true
  - 证据：①问题28（原书 p153-164）立"两范式"；②案例 c08（分数乘分数，前测四环节）示范个体范式；③案例 c46（三次备课两轮打磨）示范群体共生范式。
- V2_predictive_power: passed true
  - novel_question：一位老师单干 vs 一个备课组，课例研究怎么做？
  - derived_answer：用两范式推——单干者用"基于前测四环节"（学情调查→设计→实施→效果分析，数据驱动）；备课组用"指向共生多轮跟进"（确定主题→预案→实践→诊断→反思，行为跟进多次反复）。可推：范式选择取决于"个体还是群体"。
- V3_exclusivity: passed true
  - why_not_common：明确把课例研究按"适用对象"拆成两种范式并给不同结构，普通理解只把课例当"听评课"，作者区分了前测驱动与共生跟进的本质差异。
- → 进入阶段 2

### v-fa-04 个案研究 + 典型非代表性（结论为启示非推广）
- type: framework
- 合并来源: f42, t24, c48, ce27
- V1_cross_domain: passed true
  - 证据：①问题29（原书 p168-174）立方案结构并强调"典型但不具代表性"；②反面 ce27"个案结论误当普遍规律"；③案例 c48（知识地图新手教师）示范严谨个案设计。
- V2_predictive_power: passed true
  - novel_question：跟踪了一个"学霸"的学习方法，能写进全校方案吗？
  - derived_answer：用"典型非代表性"推——单一个案只能给"启示/认同"，不能直接推广为普适策略；结论须表述为"该生呈现……倾向"，而非"所有学生都……"。可推：要推广须补大规模调查。
- V3_exclusivity: passed true
  - why_not_common：作者死死按住"个案典型但不具代表性、结论是启示不是规律"这一方法论戒律，专门设反例章节（ce27）警示，这是外行最易犯的推广谬误，属作者强差异化洞见。
- → 进入阶段 2

### v-fa-05 实验研究两适合（确认性实验 + 准实验）
- type: framework
- 合并来源: f43, t26, c49, c50, ce28
- V1_cross_domain: passed true
  - 证据：①问题30（原书 p163-170）立"两适合"；②反面 ce28"不适当地做实验/误用因果"；③案例 c49（自主学习准实验）、c50（扇形面积等组比较实验）双示范。
- V2_predictive_power: passed true
  - novel_question：想证明"某教学法更有效"，但没法随机分班，能做实验吗？
  - derived_answer：用"两适合"推——一线不做标准真实验，改用"准实验"（以原教学班作实验/对照班，前测后测对比）或"确认性实验"（确认对象是否具假说特征）。可推：只要控好自变量、用原班对照，仍可得出可信因果判断。
- V3_exclusivity: passed true
  - why_not_common：为一线教师划出"确认性实验+准实验"的适用边界，并明确"不是所有研究都要做实验、只需相关/描述研究时别硬上因果"，这是针对一线条件的务实边界设定，非教科书式罗列。
- → 进入阶段 2

### v-fa-06 文献研究三方式（泛在 / 围绕主题 / 就一节课）
- type: framework
- 合并来源: f45, t28, c51, c53, ce29
- V1_cross_domain: passed true
  - 证据：①问题31（原书 p168-176）立"三方式"；②反面 ce29"一线教师忽视文献研究"；③案例 c51（商不变性质历史视角一课研究）、c53（PBL 文献综述报告）双示范。
- V2_predictive_power: passed true
  - novel_question：小学数学老师没时间读文献，怎么"做文献研究"？
  - derived_answer：用"就一节课的教学进行文献研究"推——收集不同时期名师同课题演绎（如"商不变性质"四省市/省编/新课标三版教学设计比较），成本低、收获大，站在前人肩上而不必读理论巨著。
- V3_exclusivity: passed true
  - why_not_common：把文献研究从"专家写理论文章"解放为一线可用的三种轻量切入点，尤其"一课研究"模式是具体可操作的下沉路径，矫正了"文献研究是教授专利"的偏见。
- → 进入阶段 2

### v-fa-07 教学微调查四步（定内容 / 设计活动 / 分析建议 / 课后再调查）
- type: framework
- 合并来源: f46, t29, c07
- V1_cross_domain: passed true（单一章节但完整展开：框架+范文+三操作要点）
  - 证据：①问题32（原书 p173-186）立"四步"并附"三操作要点（针对性/科学性/实证性）"；②案例 c07（加法的初步认识，课前测—教学—课后测）完整示范闭环。
  - 说明：微调查仅在问题32专章充分展开（框架陈述与 c07 例同为问题32，属同一语境），V1 为"单章但充分论证"，因 V3 强且结构完整，予以通过并标注。
- V2_predictive_power: passed true
  - novel_question：学生都说"会了"但一考就错，怎么办？
  - derived_answer：用四步推——定内容（测"意义理解"而非仅"会算"）→设计活动（问卷+微型访谈）→分析（诊断"会的"仅停留机械运算）→课后再次调查验证教学成效。可推：微调查能把"自以为会"变成"实证诊断"。
- V3_exclusivity: passed true
  - why_not_common：把"课堂嵌入式小调查"系统化为"前测-教学-后测"闭环并明确三操作要点，让课堂从"经验判断"走向"实证"，这是具体可落地的轻量调查方法，普通教师多靠"感觉"。
- → 进入阶段 2
