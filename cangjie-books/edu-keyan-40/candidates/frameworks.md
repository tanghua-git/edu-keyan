  title: 科研成长价值链「研中明—明中得—得中立—立中成」
  type: framework
  source_chapter: 自序（原书 p1-2）
  source_quote: "教育科研做得扎实，可以让教师经历'研中明，明中得，得中立'的过程，最终走向'立中成'。"
  summary: |
    一条描述"课题研究如何驱动教师专业成长"的推理链/心智模型：
    1. 研中明——在思辨问题与寻找方法中对问题本身认识更清晰；
    2. 明中得——理念与行为冲突、反思磨砺中，行为状态发生改变（得）；
    3. 得中立——把方法策略内化、站在更高角度思考，形成个人教学风格（立）；
    4. 立中成——对专业自我认同，自觉发展。
    用于向一线教师论证"做课题=专业成长"的价值逻辑，属跨阶段的底层心智模型。

- id: f03
  title: 选题两维度（应然/实然矛盾 + 整体/局部关联）
  type: framework
  source_chapter: 第1章 问题1（原书 p3-12）
  source_quote: "一是分析应然与实然的矛盾冲突；二是把握整体与局部的内在关联。这两个维度是课题研究价值所在。"
  summary: |
    选题时挖价值的两条基本思考维度：
    维度一——应然（理论/政策导向决定的"应该的样子"）与实然（实际样子）的矛盾，即选题着眼点；
    维度二——整体视角（如素养）与局部视角（如某教学路径）的关联，借此创新研究视角、找抓手。
    两维度均引导教师"从小处着手，把小题做大"，可迁移到任何学科/学段的选题。
  tags: [decision, topic-selection, value]
  target_skill: xuanti

  summary: |

    思路二——学习前瞻性教育教学理念后结合实践提出课题（适合有探索创新意识者）。
    是选题两维度（f03）在"教师特质"层面的操作化入口。

- id: f05
  title: 问题→课题四步（专业内涵/价值判断/可行性聚焦/逻辑结构细化）
  type: framework
  source_chapter: 第1章 问题2（原书 p7-12）
  source_quote: "将教育教学问题提炼成课题，从专业内涵剖析、内外价值判断、可行性聚焦、逻辑结构细化四个维度探讨。"
  summary: |
    把"客观存在的问题"转化为"可研究的课题"的四步推理法：
    1. 专业内涵剖析——从学科专业维度剖析本质、查原因；
    2. 价值挖掘——内部价值（对本学科实践指导/创新）与外部价值（对其他内容借鉴）；
    3. 可行性聚焦——客观/主观/时机三条件，从小处着手适度聚焦；
    4. 逻辑结构细化——分解子问题，区分核心概念思考与策略路径思考。
    四步对应"问题变课题"必须过的四关。
  tags: [reasoning, problem-to-topic, transformation]
  target_skill: xuanti

- id: f07
  title: 实践问题三层面（宏观/中观/微观）
  type: framework
  source_chapter: 第1章 问题3（原书 p12-19）
  source_quote: "从相对宏观、中观与微观三个层面生成、挖掘研究课题：学校整体发展、条线或学科实践、微型节点问题。"
  summary: |
    从"自身教育教学实践"挖课题时的三层视角：
    宏观——学校整体发展规划类（校长层面，多轮申报逐步深入）；
    中观——某条线工作/某学科教学类（管理者或学科教师）；
    微观——微型节点问题（小课题/个人课题，最易被一线教师喜欢）。
    三层面决定了课题体量、申报层级与"做实易创新难/创新易做实难"的不同张力。

- id: f08
  title: 微型课题三要求（亮特色/显个性/蹭热点）
  type: framework
  source_chapter: 第1章 问题3（原书 p19-21）
  source_quote: "从自身实践生成微型课题时，须关注三方面：一是亮特色，二是显个性，三是蹭热点。"
  summary: |
    做"实"容易、创"新"难的微型课题，立项时必须回应的三项要求：

    显个性——体现自身工作特色与研究特点（微观选题更易放大个性化）；
    蹭热点——抓住改革热点创新自身实践。
    用于自检微型课题是否"有新意、可落地"。

- id: f09
  title: 热点选题三方式（直接探索/理念融入/技术应用）
  type: framework
  source_chapter: 第1章 问题4（原书 p17-21）
  source_quote: "从教育教学改革热点选题，'直接探索'式、'理念融入'式、'技术应用'式不失为好方法。"
  summary: |
    把改革热点变成课题的三种切入方式：
    直接探索——把热点内容直接引入日常教学（开创性、常"零起点"）；
    理念融入——把新理念融入原有行为，思辨新旧矛盾冲突（中观/微观皆宜）；
    技术应用——微观具体方式/策略的实际引用（如微课、PISA能力维度）。
    热点选题"创'新'容易，做'实'难"，用此三方式可系统规划落地路径。
  tags: [decision, hot-topic, topic-selection]
  target_skill: xuanti

  source_quote: "从经典理论学习生成课题，可基于本领域经典理论、也可基于跨领域经典理论两个层面思考。"

- id: f11
  title: 他人经验四方式（直接引入/联想迁移/延展深入/深度改造）
  type: framework
  source_chapter: 第1章 问题6（原书 p27-32）
  source_quote: "在他人经验启发下，可通过引入、联想、延展与改造四种方式选取教科研课题。"
  summary: |
    借他人经验生题的四种递进式方法：
    直接引入——直接借鉴成功经验（重科学审慎移植）；
    联想迁移——把某方法从一学科/内容迁移到另一学科（如发生教学法→概念教学）；
    延展深入——以他人经验为起点作纵向深入（如导学稿→课内导学单→单元复习卡）；
    深度改造——创造性引用、理念承继+方法拓展（如错题辐射复习法突破思维导图定式）。
    四方式创新意味递增，须贴合自身状况、着眼问题解决。
  tags: [decision, experience, topic-selection]
  target_skill: xuanti

- id: f12
  title: 已有成果深入两方向（形而上思辨/形而下实践）
  type: framework
  source_chapter: 第1章 问题7（原书 p32-37）
  source_quote: "在已有研究成果基础上深入，可通过'形而上的思辨'与'形而下的实践'确立深入研究的课题。"
  summary: |
    有前期课题基础的教师，寻找新生长点的两个角度：
    形而上——深度思辨、理论建构为着力点（厘清核心概念/关键策略本质，适合名师）；
    形而下——深入探索、实践路径为生长点（思考—实践—再思考—再实践，贴近一线）。
    两者常配合：理论解释精准化，实践路径具体化，共同支撑成果专著化与推广。

- id: f13
  title: 课题名称结构体系（常规三结构 + 创新三结构）
  type: framework
  source_chapter: 第1章 问题8（原书 p36-52）
  source_quote: "课题名称表述从常规模式和创新模式出发，常规有三种基本结构，创新有三种结构。"
  summary: |
    命名课题的名称结构分类框架：
    常规模式——①三要素基本结构（对象+内容+方法）；②"理论依据/背景+"结构；③"自变量+因变量"结构；
    创新模式——①关键词前提结构（关键词：对象+内容）；②自创"数概括"结构（三化两制等，慎用）；③特色亮点明示结构。
    不论哪种，最基本要求是第一时间讲清"研究什么+怎样研究"，再适度创新，忌为创新而创新。
  tags: [structure, naming, expression]
  target_skill: xuanti

- id: f14
  title: 名称三类典型毛病（关键词多/对象不清/逻辑不清）
  type: framework
  source_chapter: 第1章 问题8（原书 p37-39）
  source_quote: "课题名称表述典型问题：一是关键词太多；二是研究对象不清晰；三是研究内容间逻辑关系不清。"
  summary: |
    自检课题名称的诊断框架（反向校验 f13）：
    毛病一——关键词堆砌，研究内容不明确、难聚焦；
    毛病二——研究对象不清（如"'家园联盟式'环保意识培养"不知指向谁）；
    毛病三——变量间逻辑关系不清（如"课前预设与课堂调控对学习动力"关系不明）。
    写名称前用三类毛病逐条排查，可避免立项被否。
  tags: [diagnostic, naming, checklist]
  target_skill: xuanti

- id: f15
  title: 研究方案三问（研究什么/怎样研究/预期效果）
  type: framework
  source_chapter: 第2章 问题9（原书 p45-60）
  source_quote: "各级各类课题方案核心：讲清楚研究什么、怎样研究和预期的效果。万变不离这三问。"
  summary: |
    方案设计的顶层母框架，也是"想好了做研究"的落地：
    研究什么——选题意义、价值、主要内容（起点）；
    怎样研究——策略、路径、方法、计划（关键，想不清常致不被立项）；
    预期效果——基于假设的验证过程，明确方向与聚焦点（体现科学性）。
    一切方案七要素（f20-f22 等）都可归入这三问之下组织。
  tags: [structure, scheme, three-questions]
  target_skill: fangan

- id: f16

  source_quote: "课题研究背景一般包括时代背景、理论背景及实践背景三个方面，三者不割裂，依选题视角分析。"
  summary: |

    理论背景——影响选题的理论因素；
    实践背景——实践对选题产生影响的条件。
    三者结合实际写作，最终落到"研究价值判断有说明"，回答"为什么要研究"。

- id: f17

- id: f21
  title: 核心概念界定两方式（本义→特指义 / 内涵+外延）
  type: framework
  source_chapter: 第2章 问题12（原书 p59-68）
  source_quote: "给核心概念下定义有两种方式：从概念的本义和特指义两个层面依次下定义；从概念内涵与外延两个维度分别阐述。"
