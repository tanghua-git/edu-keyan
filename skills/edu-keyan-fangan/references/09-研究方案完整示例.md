# 09 · 研究方案完整示例：「区块链+：整本书阅读"双区块"架构与研究」

> 范文来源：北京师范大学南湖附属学校课题组，浙江省规划课题（立项编号 2019SC095），
> 原书 p84—92，选入时有删改。案例标签：【浙江·小学语文】。
> 用法：不作为照抄模板（"区块链+"是 2019 年热点话语，今天勿照搬此概念），
> 重点看**结构骨架与七要素如何咬合**。批注用【亮点】【注意】标注。

## 一、选题缘由（对应 F02 + F03）

**结构**：源流梳理 → 现状审视（三问题）→ 相关综述 → 创新点提出。

1. **源流**：整本书阅读可追溯到近代语文单独设科——梁启超提出读整本文言读物、胡适明晰、叶圣陶集大成（"心志可以专一，讨论可以彻底"）。
2. **现状审视**——三个归并后的问题维度：
   - **伪阅读**：碎片化阅读缺连续性、缺深层精神交流，弱化整本书阅读沉淀；
   - **书单阅读**：时下书单缺科学性逻辑性，学生在大人推荐的书单下阅读，干扰阅读生长；
   - **断层阅读**：课内重教材文本、课外只推荐书目不指导，课内课外无链接，阻碍阅读伸展。
   【亮点】问题三维度归并（F03）——每维度"四字命名 + 事实描述"，结构清晰，直接为后文"双区块"策略埋下对应关系。
3. **相关综述**：格式塔理论提供心理学基础（"整体不等于部分之和"）；国内外实践（北师大亚太实验学校、江苏海门新教育阅读节、美国"真实阅读"课堂）提供实践基础。随后总评：已有课程多建立在教师主导推荐、指导、评价上，"学生自我的阅读选择、阅读爱好、阅读情感却难以表达和保护"。
   【亮点】有综有述有评（F04），总评直接点出空白——即本课题突破点。
4. **创新点**：改教师主导为"以生为本+教师指导"并轨；把"阅读资源+阅读教学+阅读分享"链接为课内外并进——"双区块"。

## 二、概念界定（对应 F06 + F07）

- **区块链+**：区块链普遍定义为"加密的分布式记账技术"，每录入一个数据创建一个新区块、彼此嵌合；本课题中特指"将区块链技术理念运用于教学"。
- **"双区块"架构**："以生为本"+"教师指导"并进的**并轨区块**；"阅读资源"+"阅读教学"+"阅读分享"链接的**并进区块**。

【亮点】用"本义→特指义"方式（F07）把一个技术概念转化为教学概念，避免概念漂移。
【注意】借技术热词命名课题是 2019 年做法，热点迁移性强；今天使用新概念须确认其当下适切性（见 `00-当代适配.md`）。

## 三、研究目标（对应 F08）

1. 建构整本书阅读中"以生为本+教师指导"**并轨区块**；
2. 创新"阅读资源+阅读教学+阅读分享"**并进区块**；
3. 改革整本书阅读的机制、策略，促进学生形成更具科学性、发展性和长远性的**阅读素养**。

【亮点】目标 1、2 是本体目标（产出两个区块的机制与策略），目标 3 是对象目标（学生阅读素养）——三维度归位，且与"双区块"界定严格对仗。
【可更优】目标 3 较抽象，可再具化为可观测的阅读行为指标（F08"越具体越好"）。

## 四、研究内容与操作实施（对应 F09 + F10 + F11）

**总架构**：并轨区块（观念角色·阅读机制）+ 并进区块（内容流程·阅读策略）= 新区块（阅读素养提升·阅读愿景）。配"双区块"架构图与组合操作图。

**实施路径**：
1. 组合式推进"双区块"实施模型；
2. 并轨区块思想建模——阅读观念从"教师为中心"转向"以生为本、教师指导"共同推进；
3. 并进区块策略建模——阅读资源（书单推荐/自主推荐）→ 阅读教学（课内/课外）→ 阅读分享（分享/独享）组合接力。
【亮点】路径写的是内容逻辑链（F09），且每条策略链都有下位动作。

**操作策略具化**（F11 的典型示范）：

- **书目体系**："书单推荐"以课内文本为"源点"四形式——**一课一文 / 一课一本 / 一课多本 / 多课一本**；据此建课外阅读"源库"；"自主推荐"双选择——自由选择自主阅读 + 同伴推荐互相共享。
- **课内到课外的链接**："课内文本+课外文本"融合教学，**"四衍生"策略**——体裁衍生、人物衍生、观点衍生、作者衍生；再由课外文本激发阅读整本书，实现"一篇→整本"过渡（配操作流程图）。
- **评价机制**："阅读分享+阅读独享"双轨。分享端从三个角度具化——按时间（读前指导/读中跟进/读后反馈）、按体式（童话/散文/小说）、按方法（浏览泛读/品味精读/读写结合）；空间上"学校+家庭+社会"多渠道；引入模拟"比特币"的奖励机制。独享端呵护个体精神成长。

【亮点】策略全部具化为"命名 + 动作清单"：四形式、四衍生、三角度——组员拿到方案即知做什么动作（F11 动词式/图表式的复合运用）。
【注意】"比特币奖励"是借用当时概念，实践中应换成班本化的激励设计。

## 五、预期成果（对应 F08 的对照检验）

1. **课外阅读书目库**："自主推荐"+"书单推荐"双资源，科学性与开放性一体；
2. **整本书教学模式**：实践层面稳固形成四种教学模式，促成"一篇→整本"过渡；理论层面形成《区块链+：突破传统课外阅读指导模式思考》等论文；
3. **双轨评价反馈机制**：促进阅读能力、意志、习惯与素养的长远发展。

【亮点】三条预期成果与三条研究目标、三个策略板块逐条对仗——用 `08-方案逻辑对应自检表.md` 勾稽全部通过：问题（伪阅读/书单/断层）→ 双区块 → 目标 1/2/3 → 策略（书目/链接/评价）→ 成果（书目库/模式/机制），逻辑闭环。
