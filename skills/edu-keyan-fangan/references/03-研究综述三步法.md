# 03 · 研究综述三步法：搜集 / 归类 / 述评 + 四用四不用

> 对应单元：F04（文献综述三步）、F05（文献筛选四用四不用）。
> 来源：问题11（原书 p54—58）。

一线教师做课题也要写综述。综述的价值有二：对相关领域有完整了解；打开视野、反思并调整自己课题的方向、内容或策略。**不写综述（ce15）与只堆材料（ce14）是两个高频失分点。**

## 一、三步流程（F04）

### 第一步：搜集资料
从核心研究点出发广泛涉猎。操作方法：
- **关键词扩展**：由宽到窄设一串检索词，如"数学活动 → 数学活动教学 → 小学数学活动教学 → 数学活动特质"，观察文献量变化，确定研究重心与切入点；
- **平台**：知网、龙源期刊、人大书报资料中心等；以"篇名/关键词"为检索项，精确匹配。

### 第二步：归类整理
- **时间跨度筛选**：给定跨度（如近 10—15 年），过早的略去；
- **内涵扩展收敛**：加限定词把文献量控制在可深读的范围（书中案例：控制在 50 篇以内）；
- **按研究侧重点分簇**：如按"概念认知 / 试题解析 / 阅读教学"分簇，便于后续述评。

### 第三步：分析述评
> 原书："课题研究中'相关研究综述'的基本要求是有综、有述、有评，做到'综而述之''有述有评'，在此基础上明晰自身课题的研究方向和研究突破点。"（问题11，原书 p54）

- **综而述之**：把他人成果或观点分门别类呈现；
- **述而评之**：分类评 + 总评结合；
- **落点**：结尾必须写明已有研究的不足/空白——即本课题的突破点。

**反例（ce14）**：综述全是他人观点罗列，无分析无评论，看不到"本研究由此切入"的落点。

## 二、文献筛选：四用四不用（F05）

> 原书："能用一手资料的，不用二手资料；能用权威资料的，不用一般资料；能用正式出版资料的，不用内部资料；能用直接资料的，不用间接资料。"（问题11，原书 p53）

| 用 | 不用 |
|----|------|
| 一手资料（原始研究、政策原文） | 二手资料（转述、引用链） |
| 权威资料（核心期刊、经典著作、官方文件） | 一般资料（普通网文、自媒体） |
| 正式出版资料 | 内部资料（未刊稿、内部交流） |
| 直接资料（亲自读到的原文） | 间接资料（道听途说、AI 转述） |

**反例（ce16）**：关键概念以二手来源界定、大量引用博客/内部稿——论证质量与可信度双降。

> **AI 合规红线**：AI 可帮拟检索词、梳理脉络，但**严禁编造文献**；每条引文必须核验到原文再引用。详见 `00-当代适配.md` 第二节。

## 三、述评样例：非连续性文本研究综述（结构拆解）

案例【上海·语文】潘红《近年来非连续性文本研究文献综述》（《上海教育科研》2015(10)）：

- **搜集面**：2002—2012 年间 245 篇相关文献；
- **归类**：确定"概念认知、试题解析、阅读教学"三个研究点，精选 18 篇综述；其中"概念认知"8 篇再分"概念 / 类型 / 特点"三部分；
- **述评**（概念部分）：先分述 PISA 测试的定义、新课标的界定、国内学者（张年东、许锦）对"非连续"的歧义理解；再作总评——"研究者们逐渐脱离表格这一框架形式限定……这一转移使非连续性文本丰富了内涵、扩大了外延"。

这则综述**有分而述之、有述而评之、分评与总评结合**，读者能对研究现状有完整了解——是一线可模仿的述评结构。
