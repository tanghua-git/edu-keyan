# 06 · 研究内容与路径：内容三呈现 + 路径三型 + 路径≠程序

> 对应单元：F09（研究路径三型）、F10（工作程序 vs 研究路径）。
> 来源：问题14（原书 p69—73）、问题15（原书 p74—78）。

研究内容讲清"研究什么"，研究路径讲清"怎样研究"。

## 一、研究内容三呈现方式

内容呈现须把握三个基本要求：**知晓整体**（研究什么、分几部分）、**说明逻辑**（要素间关系）、**简洁明了**（少文字或简洁图表）。三种方式：

| 方式 | 适用 | 案例 |
|------|------|------|
| **文字表述法** | 内容维度少、逻辑简单；平实易接受 | 【浙江·小学】家庭作业创新课题：从目的、内容、形式、承担者、时间、评价六个角度说明创新点 |
| **表格呈现法** | 内容可分维度对照 | 【浙江·幼教，省教研课题 041001】主题活动管理创新：管理内容（设计/实施/反思评价）× 关注形式（教案/课堂/反思日志）× 创新要点 |
| **图文并茂法** | 要素间逻辑关系复杂；最常用 | 【浙江·小学数学，省教研课题 13A219】"学为中心"：以"学生的学"为圆心，分出提问/尝试/交流/建模/应用五个关键动作，再配文字逐条解释 |

注意：图是为内容逻辑服务的，**不是为画图而画图**——图过于复杂花哨反而干扰理解（见 `07-操作策略具化.md` 与反例 ce22）。图表呈现后应配文字说明，如"学为中心"课题在图后逐条解释五个关键动作的含义。

## 二、研究路径三型（F09）

研究路径 = 基于**内容逻辑**设计深入研究的整体思路，反映选题来源、表明研究着力点。三种基本型：

| 类型 | 实质 | 适用选题 | 案例 |
|------|------|----------|------|
| **① 理论→实践** | 理论思辨、文献研究在前，实践研究在后 | 来源于热点或理论应用的选题 | 【浙江·初中，省教研课题 04325】"学为中心"作文教学：理解特征要点 → 思辨价值 → 探索课堂结构与操作要点 → 构建基本模型 |
| **② 理论实践并举** | 思辨与探索同步，"边实践边反思边提炼" | 源自实践问题且有一定理论背景（如课程开发类） | 【浙江·幼教，省教研课题 04-1-20】"玩耍"运动课程：基本要素/开发途径/实施策略三维度同步推进 |
| **③ 问题归因—实践解决** | 起于问题产生、归于问题解决 | 实践性强的课题、微型（个人）课题 | 【浙江·小学数学】读图能力课题：分层操作步骤 → 课堂操作途径 → 典型操作策略 |

**选径建议**：选题蹭了热点/用了新概念 → 型①（先把概念与价值思辨清，否则实践缺根基）；做课程开发与实施 → 型②；从自身教学痛点出发、微型课题 → 型③。一线教师以型③最常用。

无论哪型，进入总结阶段都必须再做理论提炼与思辨——路径只管研究过程。

## 三、工作程序 ≠ 研究路径（F10）

> 原书："课题的'研究路径'与'工作程序'（有时也称'行动路径'）的区别……工作程序更多是指工作性质的推进过程或研究步骤设计……研究路径是基于研究课题内容逻辑设计深入研究的整体思路与具体实践路径。"（问题15，原书 p74）

| | 研究路径 | 工作程序 |
|---|----------|----------|
| 坐标 | 内容逻辑（研究什么→怎么深入） | 时间顺序（何时做什么、谁做） |
| 回答 | 怎样研究 | 怎样推进 |
| 样子 | "反馈设计→行为干预→成效验证" | "第一阶段准备→第二阶段实施→第三阶段总结" |
| 位置 | 方案主体 | 常与阶段分工、时间表合写 |

**反例（ce20）**：把"立项→实验→总结"当研究路径——那只是时间表，评审会判"怎样研究没想清"（关联 ce21：意义价值颇大却未立项，多源于此）。

**反例（ce19）**：一张内容框架图里混画研究内容、时间节点、分工箭头——逻辑混乱，读者抓不住核心。内容框架与工作程序**分开呈现**。

工作程序示例【浙江·区域】"绿色评价"课题行动路径：三阶段（理论学习内涵理解 → 多部门联动整体推进 → 梳理提炼总结成果），每阶段配研究主体（教育科/教研室/督导室）与研究任务——这是合格的工作程序写法，但它不替代研究路径。

## 四、本板块自检

- [ ] 研究内容呈现方式与内容复杂度匹配，图表简洁、配文字说明？
- [ ] 路径三型中明确选定一型，且与选题来源匹配？
- [ ] 研究路径写的是内容逻辑链，不是阶段时间表？
- [ ] 工作程序（阶段/分工/时间）单独成段，与路径分写？
