# 04 · 课题界定：两层次 + 核心概念界定两方式

> 对应单元：F06（课题界定两层次）、F07（核心概念界定两方式）。
> 来源：问题12（原书 p59—63）。

课题界定是对研究核心内容作深入思考的过程，是方案的**逻辑起点**。界定不清，后续目标、内容、策略都会漂移。

## 一、两层次（F06）

| 层次 | 回答什么 | 操作 |
|------|----------|------|
| **核心概念界定** | "是什么"——研究方向 | 给来自课题名称的核心概念下定义（两方式见下） |
| **研究范围界定** | "研究到哪"——内容边界 | 写明学段/学科/对象/周期等边界，避免研究失焦 |

核心概念 = "能够集中反映课题研究主题或主要内容的概念"，一般来自课题名称（如"小学生'长作业'设计的实践与研究"中的"长作业"）。

## 二、核心概念界定两方式（F07）

### 方式一：本义 → 特指义（依次增加定语）
先引概念本来的意思（词典或已有研究界定），再落到"本课题中它指什么"。

案例【作者本人课题·小学数学】"小学数学活动教学研究"界定"数学活动"：先引《现代汉语小词典》"活动是为达到某种目的而采取的行动"，再给出特指义——为学习数学知识、习得技能、发展思维而采取的行动，强调"很强的目的性"；并补充新课程理念下还应有"数学思想的体验与基本活动经验的形成"。

案例【浙江·初中历史与社会】"错题辐射复习法"课题：复习法 → 辐射复习法 → 错题 → 错题辐射复习法，依次增加定语，逐步聚焦。

### 方式二：内涵 + 外延（分别阐述）
内涵 = 本质属性；外延 = 所包含的范围（及与近似概念的区别）。

案例【浙江·体育】"领会教学法"界定：
- 内涵——"教师遵从学生认识运动世界的规律，让学生全身心参与到运动中去，在运动中认识世界的方法"；
- 外延——"并非'直观法''讲解法''练习法'那样狭义的教学方法，而是超越传统体育教学方法论的一种新的体育教学方法论"。

案例【浙江·小学语文】"随文练笔"课题界定"语用"：先下定义（"学生在语文教学中对母语运用的学习及言语运用实践活动"），再补三个特征（基础是理解内化 / 需经理清辨析讨论 / 应在参与互动的语言实践中练习），使概念丰满。

**选用建议**：概念有公认本义时多用方式一；新概念、易混淆概念用方式二，外延部分专门与近似概念划界。两方式也可在同一课题中分概念使用。

## 三、研究范围界定

在概念厘清后，明确研究边界：学段、学科、对象群体、研究周期、不含什么。防止"题太大"和研究进程跑偏。

## 四、完整界定示例：「言语能力建构」（浙江·小学语文，省教研课题 042023）

课题：阅读教学中学生言语能力建构的策略研究。

**(一) 核心概念的界定**（逐层聚焦：言语 → 言语能力 → 言语能力建构）

> "言语"是运用语言说与写的行为过程和结果，其基本特征有三：一是动态性，它是语言系统中各种成分的自由结合；二是主观性，它与个体的思想认识、表达水平、生活经历等因素密切相关；三是个性化，个人言语生成的结果具有鲜明的个人特色。（问题12，原书 p59）

> "言语能力"是指个体在与他人交往时运用语言工具顺利进行信息传递的稳定的心理结构。在语文学科中，它包括听、说、读、写四个方面。……言语能力具有阶段性、反复性、实践性等基本特征。（同上）

> "言语能力建构"是指学生在学习和运用语言的实践过程中形成言语能力的过程，具体包括阶段性目标的合理设置、言语技能的反复训练、言语实践活动的开展等内容，其中学生是言语能力建构的主体。（同上）

**(二) 研究范围的界定**

> 本课题侧重阅读教学，以言语能力中读和写的能力作为主线，通过课例研究，形成在阅读教学中学生言语能力建构的可操作性策略。（同上）

**批注**：概念界定用"本义→特指义"链条逐层收拢（言语→言语能力→言语能力建构），每层附特征说明；范围界定一句话钉死"阅读教学 + 读写为主线 + 课例研究为方法"，为后续研究内容和路径提供了清晰的逻辑起点。
