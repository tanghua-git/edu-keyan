# 04-过程性资料体系

> 对应原书问题21、问题22（原书 p114—477）。资料是结题/成果报告的素材底座，须按研究逻辑分类、及时积累。

## 一、过程性资料四类（f32 / t19）

原书（问题21，原书 p371）：课题研究实践活动产生两类目的（学习—领会、实践—反思），随之产生四类资料——

| 类 | 内容 | 子类/说明 |
|---|---|---|
| **文献政策类** | 理论文献、政策文件（应然依据） | 如国内外研究脉络、课程标准/评价改革文件 |
| **理性思考类** | 问题思考 + 概念思辨（p62 素材） | 问题思考类（归因分析、典型错例）；概念思辨类（核心概念解读，已具阶段成果特点） |
| **实践案例类** | 量表设计 + 案例分析（p63 素材） | 量表设计类（观察量表、活动记录表、计划书）；案例分析类（课例/课程/作业/德育等，须深度反思策略效度） |
| **数据分析类** | 现状调查、成效测量数据 | 如城乡 668 名学生教学方式调查（[来源：浙江/嘉兴，初中，信息技术]） |

> 不是"什么材料都留着"，而是按研究逻辑分类积累、聚焦留存。

## 二、积累三方式（f33 / p64）

### （一）依托"工作手册"（过程记载册）
贯穿全程、记录论证过程/阶段性成果/经费等的工具，是过程管理手段。各地科研管理机构多有类似要求（如省教研课题"记载册"、市级"过程记录册"），**具体格式以本地教育科研管理部门最新要求为准**。

### （二）借助"档案工具"
实物档案袋（利于收手工原始材料）或电子档案袋（利于存储/传送/分析）。用档案袋**必须做三动作**（p66 素材）：
- **归类**：不同类型分类，便于后续分析调取；
- **编码**：编目录、做文件夹，便于按时间/内容查阅；
- **总结**：对原始资料作数据分析（如调查后整理、活动后片断分析），便于后续省时聚焦。

> 当代升级：直接用网盘/知识库/多维表格替代实物档案袋，保留归类—编码—总结三动作（见 `00-当代适配.md` ①）。

### （三）编制"研究简报"
结构化梳理资料、展示思路、分享成果。适合**周期长（一般两年以上）、内容中观及以上、参与面广**的课题。栏目框架见 `06-研究工具模板库.md`。

## 三、给用户的操作清单

1. 建四个资料库（按四类分目录/标签）；
2. 选一种积累工具（记载册 + 电子档案 + 简报组合）；
3. 立"归类—编码—总结"规矩，每次活动后当周归档；
4. 跨校/跨时段课题优先建共享"文献政策类"基线库，避免各说各话。
