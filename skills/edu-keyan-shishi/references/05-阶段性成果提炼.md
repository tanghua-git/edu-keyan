# 05-阶段性成果提炼

> 对应原书问题23、问题24（原书 p124—681）。核心：边做边提炼，服务思辨、审思、预期与动力。

## 一、及时提炼四意义（f34 / p67）

原书（问题23，原书 p511—577）从四方面论证"为什么要边做边提炼"：

1. **深度思辨研究问题的需要**：问题有实践表现层与概念本质层，归因可用经验/调查/理论多种方法，调查数据使归因更具说服力（例：新闻微评论课题先调查再数据归因，[来源：浙江/嘉兴，初中，语文]）。
2. **审思阶段研究效果的需要**：常做阶段梳理，调整策略；围绕"核心概念思辨"与"实践活动总结"两层。
3. **完成研究预期成果的需要**：许多立项课题对预期成果有硬性规划（如国家级/教育部课题要求专著+系列核心论文），须及时总结投稿才可能完成。
4. **研究人员动力激发的需要**：展示思路、分享经验带来成就感，同伴结伴同行、相互启发共同成长。

> 反例（ce25）：只做不写、结题才拼凑，错失深度思辨/审思效果/动力激发的时机。

## 二、总结两样式（p68 / t20）

| 样式 | 要点 | 注意 |
|---|---|---|
| **观点论文** | 对研究假设作逻辑推断、理性思考，揭示普适规律；结构=引言+本论+结语，含摘要/关键词/参考文献 | 要求理论性与科学性，不是随笔 |
| **案例分析** | 典型事件 + 围绕主题的分析评判与规律提炼（教育案例/教学课例两类） | 不是流水账（p70 素材）：事件描述与规律提炼相辅相成，生动性与主题性兼顾 |

此外还有随笔、叙事等灵活写法——关键是有针对研究问题的思考剖析、能归纳出有效策略。

## 三、发布三样式（p69）

1. **成果发表**：单篇或成组（多篇成组更具冲击力）。常识（p71 素材）：①按成果形式选刊物（论文投论文类、案例投案例类杂志，先关注风格）；②按杂志要求选方式（纸质稿/邮箱稿、注意格式与邮件名细节）。
2. **会议交流**：主动交流（专门召开推广会，需较完整材料、全体参与）；参与交流（依托上级会议/活动作专题展示，可只交文本）。
3. **实践展示**：需"思考层面 + 实践层面"双准备，体现规律可重复、可验证，更具直观冲击力。

## 四、给用户的操作清单

- 定节奏：把"边做边提炼"设为研究基本节奏，每次阶段活动后产一篇论文/案例雏形；
- 选样式：概念/规律类写观点论文，事件/课例类写案例分析；
- 选发布：先投合适刊物，再争取会议/展示；
- 落资料：所有阶段性成果归入"理性思考类/实践案例类"资料库（见 `04`）。
