# edu-keyan-shishi（课题研究过程实施指导）

> 本技能蒸馏自费岭峰《怎么做课题研究——给教师的40个教育科研建议》第三章（问题17—24），
> 经仓颉三重验证（V1 跨域 / V2 预测力 / V3 独特性）通过 6 个方法论单元，并按原书晋级。
> 配套 references/ 提供当代适配、关系辨析、开题、参与、资料、成果、模板库七份文档。

## 一、何时用（When）

当用户已经拿到立项通知、进入"方案落地→过程推进→中期/阶段总结"这一阶段时使用：

- 要组织开题论证（写开题报告、请专家、开论证会、论证后改方案定计划）；
- 要设计研究活动：区分"学习—领会"与"实践—反思"，或判断自己的活动有没有"研究味儿"；
- 要带课题组：解决成员挂名、深度参与不足的问题；
- 要建过程资料体系：知道积累哪四类、用什么方式、怎么归档；
- 要做中期交流或阶段性成果提炼、发布（论文/案例/会议/展示）。

不适用（请转兄弟技能）：写研究方案或申报书 → `edu-keyan-fangan`；决定用哪种研究方法、怎么设计调查/课例/实验 → `edu-keyan-fangfa`；写结题报告或成果报告 → `edu-keyan-chengguo`。

## 二、核心方法论骨架（Interpretation，用自己的话）

课题立项之后，"过程质量决定成果质量"。把第三章拆成一条主线、六块能力：

1. **研究味儿四标志（辨真伪）**：一线教师的研究活动常混同日常教学。真正的研究有四个可检核标志——有围绕主题的假设、有依据假设的分析、有规律提炼的需要、有过程资料的物化。拿这四个标志一卡，就能判断一次活动到底是"上课"还是"做研究"。
2. **研究活动两类（定节奏）**：过程研究分"学习—领会"（前期多，重学习接纳：方案解读+理论学习）和"实践—反思"（贯穿全程，重行为跟进：操作+研讨+数据）。一次有效的实践—反思须满足四要素：目标清、人人有任务、记录数据、分析提炼。
3. **成员深度参与四机制（靠机制不靠觉悟）**：挂名是结构问题不是态度问题。用工具引导（观察表/试题卡让成员被迫卷入）、有计划参与（分工+时间表）、子课题认领（纵向递进/横向并列）、阶段性分享来破解。
4. **过程性资料四类（建底座）**：文献政策类、理性思考类（问题思考+概念思辨）、实践案例类（量表设计+案例分析）、数据分析类。按研究逻辑分类积累，而非"什么材料都留着"。
5. **积累三方式 + 归类编码总结（落袋）**：工作手册/记载册、档案工具（实物/电子档案袋）、研究简报。用档案袋须做好归类、编码、总结三动作。
6. **阶段性成果四意义 + 总结/发布样式（边做边提炼）**：及时提炼服务深度思辨、审思效果、完成预期成果、激发动力；总结用观点论文与案例分析两样式，发布用发表/会议交流/实践展示三样式。

> 注意：上述均来自作者基于浙江等地课题的实践归纳，属"建议"而非"定律"，见边界 B。

## 三、执行步骤（Execution / E）

**步骤 0｜判断用户所处实施节点**
- 完成标准：能明确用户处在【A 开题期 / B 推进期 / C 资料与中期分流】中的哪一类，并说明判断依据（如"已立项未开题""正在做活动但没资料""临近中期要总结"）。

**步骤 1｜若处于 A 开题期 → 加载 `references/02-开题论证操作指南.md`**
- 完成标准：给出开题报告与方案的区别、专家 3~5 人结构、论证三环节、论证后"改方案+订计划"两跟进；如用户要写开题报告，输出可直接套用的结构。

**步骤 2｜若处于 B 推进期 → 按三件事分流**
- 2-1 活动设计（研究味儿/两类活动/四要素）→ 加载 `references/01-研究与日常教学的关系.md` 与 `references/03-成员深度参与四机制.md`；
- 2-2 资料积累 → 加载 `references/04-过程性资料体系.md`，并提示数字化方案见 `references/00-当代适配.md`；
- 2-3 工具表单 → 加载 `references/06-研究工具模板库.md` 给空表。
- 完成标准：用户拿到与其课题匹配的活动设计要点、参与机制或可直接填写的模板。

**步骤 3｜若处于 C 资料与中期分流 → 加载 `references/05-阶段性成果提炼.md`**
- 完成标准：用户能说出要提炼什么（观点论文/案例分析）、发布到哪（发表/会议/展示），并有一份可动手写的样稿或大纲。

**步骤 4｜任何涉及电子档案/AI 工具/录音转写等当代做法 → 必加载 `references/00-当代适配.md`**
- 完成标准：用户在用网盘/知识库/多维表格/ASR/AI 起草工具时，得到"数字化升级 + 课题组审定"的明确提醒，而非照搬 2019 年实物档案袋。

**步骤 5｜收尾核对边界**
- 完成标准：提醒用户作者经验为建议、热点与工具以当下为准、管理要求以本地最新文件为准（见 B）。

## 四、边界（Boundary / B）

1. **作者经验是建议，非定律**：书中方法是作者近 30 年、以浙江等地课题为主的经验归纳，存在"发达地区、教研员视角、有区域科研系统托底"的立场局限；对农村薄弱校、无团队支持的"单干"教师，部分要求（简报、档案袋、多轮磨课）须因地制宜，避免制造形式主义。
2. **热点与工具锚点以当下为准**：原书案例集中于 2010—2018 年（微课、电子书包、STEM 等），"电子档案库四优势"写于 2019 年；今天 AI+教育、云端协作、ASR 等已远超当年预判，凡涉技术表述一律以当下实际为准，不照搬过时锚点。
3. **管理要求以本地最新文件为准**：书中"记载册""规划办要求""立项编号格式""预期成果硬性规划"等均以浙江（尤其嘉兴）为样本；各地申报格式、过程管理、结题口径不同，凡属制度话语，一律注明"以本地教育科研管理部门最新要求为准"。
