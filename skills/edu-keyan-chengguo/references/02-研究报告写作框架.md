# 02-研究报告写作框架（三层质量模型 + 五部分六映射）

> 来源：原书问题34（p197—219，三层要素）、问题33（p191—198，五部分）、问题35（p202—206，文字表述四着力）。
> 用途：写研究报告/结题报告时的总框架与质量自检标尺。

## 一、三层质量模型（合格 → 好 → 出彩）

| 层次 | 内容 | 自检问题 |
|---|---|---|
| 基本要素 | 问题解决过程的完整记录（见六映射） | 报告是否覆盖"问题→归因→假设→实施→分析→结论"全程？ |
| 核心要素 | 实践的体验、逻辑的思考、创新的元素 | 有真实实践支撑吗？逻辑经得起追问吗？有新提炼吗？ |
| 增色要素 | 语言洗练准确；具体与抽象和谐；形式生动有节奏（案例、图表） | 读起来顺吗？抽象论述配了形象案例吗？ |

> "一份完整的课题研究报告，需要有基本要素、核心要素、增色要素三个内容。"（问题34，原书 p197）

**被评"合格但平庸"的升级路径**：有基本层只是合格；平庸是因为缺核心层——补实践体验（真实过程与思维转变）、补逻辑思考（针对性/条理性/科学性）、补创新元素（哪怕只在策略或案例层面）；再升增色层（语言+图表节奏）。

## 二、五部分结构与六映射

### 五部分骨架

1. 问题的提出（背景及意义）
2. 理性思辨（理论概念与核心概念界定）
3. 研究的内容及策略（设计、方法与过程）
4. 研究的成效（结果或结论）
5. 进一步思考的问题

### 六映射：把你做过的研究填进板块

| 研究过程环节 | 报告板块 |
|---|---|
| 问题 | 研究背景和意义 |
| 归因 | 核心概念界定 |
| 假设 | 研究内容和目标 |
| 实施 | 研究策略 |
| 分析、结论 | 成效分析 |

> 一般问题研究"须经历这样的过程：提出问题—分析原因—提出假设—尝试解决—分析整理—得出结论"，报告板块"正是对问题解决过程的描述或记录"（问题34，原书 p198—199，图21）。

**用法**：先按五部分搭骨架；再逐行核对六映射——你实际做过的每个研究环节，是否都有对应板块承接？缺"归因"环节的概念界定会空泛，缺"分析"环节的成效会突兀。

## 三、核心要素详解

### 1. 实践的体验

报告须"在实践基础上总结提炼，有实践过程作支撑"（问题34，原书 p202）。既包括文献检索、研究设计、实施、数据分析等活动记录，也包括行动研究中想法调整等思维转变的描述。

【案例·浙江/小学/数学】《小学数学活动教学研究》报告：四类数学活动（经历型/体验型/探究型/创生型）的提炼，背后是近 40 次围绕课题的课堂教学实践（问题34，原书 p203）。

### 2. 逻辑的思考（四体现）

1. **问题提出的针对性**——直截了当，让人一看便知针对什么。【案例·浙江/小学/语文】"结束语"课题只用几句话就点明"教师重导入轻结束、铃响匆匆布置作业"的真问题（问题34，原书 p205）。
2. **理论思辨的严谨性**——核心词界定精准。【案例·浙江/小学/语文】"关键性内容"先界大概念再落到"语文教学中能导引学习、发散阅读、深化理解的词、句、段"，为全篇定了逻辑起点（问题34，原书 p206）。
3. **研究策略的条理性**——策略三特点：围绕课题全程、层次清晰、可归纳可重复可借鉴。【案例·浙江/中小学/教师发展】姚江峰"教师小课题研究的探索"用"成果应用型/问题解决型/经验总结型/探求新知型"描述个体研究、用"多人同课/一人同课+小课题"描述群体协作，层次清晰、操作性强（问题34，原书 p208）。
4. **成效归纳的科学性**——"需要根据研究目标来梳理，而不能盲目填充"（问题34，原书 p208）。详见 `03-成效表达三维度.md`。

### 3. 创新的元素

"大而言之，整个研究过程操作层面有新的做法；小而言之，文本中的某个提炼、表达是新的"（问题34，原书 p209）。一线教师的创新多在**理论应用的实践层面**，把它梳理出来即可——不必追求整体原创。

【案例·浙江/小学/语文】刘颖"结束语"课题提炼八种结束语设计方式："抓住重点，归纳概括""借用练习，迁移训练""课末揭谜，首尾呼应""巧用语言，抒发情感""热烈讨论，激发热情""搭建桥梁，拓展延伸""设置悬疑，承前启后""郑重评述，塑造形象"（问题34，原书 p210）——蕴含研究者自己的理解，创新意韵自然呈现。

## 四、文字表述四着力（问题35，原书 p202—206）

1. **意义阐述：定位准确，有"视野"**——三个层次：从教育本质（育人价值）、教育现实（政策与真问题）、教育发展（站在前人肩膀上的创新）分别阐述。
2. **内容说明：表述明确，有结构**——核心概念从"下定义+讲特征"两层界定；研究内容宜用"文字+图表"的有结构材料呈现（如树形图呈现素养要素关系、表格呈现"要素—策略—案例"对应）。
3. **路径描述：设计明晰，有条理**——研究思路清晰可感（推进过程讲得出）、方法选择合理多元（文献/调查/个案各得其所）、研究活动可感（提炼出具体的课程开发、模式研究、个案帮扶等活动）。
4. **成效分析：讲清关联，有信度**——"策略成效明晰、对象成效显性（定性定量结合）、主体成效契合（观念与实践变化）"（问题35，原书 p260）。

## 五、完稿自检清单

- [ ] 五部分齐全，六映射无缺漏；
- [ ] 问题提出直截了当、针对真实问题；
- [ ] 核心概念界定精准（定义+特征）；
- [ ] 策略有层次、可归纳、可重复；
- [ ] 成效逐条对照研究目标，无空话（见 `03`）；
- [ ] 有至少一处实践层面的创新提炼；
- [ ] 图表适当适度（见 `04`），附件达标（见 `05`）。
