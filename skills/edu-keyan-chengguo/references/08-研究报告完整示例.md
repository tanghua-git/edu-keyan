# 08-研究报告完整示例（结构化 + 亮点批注）

> 范文：《幼儿体育集体教学活动"四有"设计与实施研究》研究报告
> 来源：原书附录"课题'研究报告'示例"（原书 p233—252）；课题组为某区教育研究培训中心（浙江/幼儿园/体育），执笔陈微；获 2018 年度省教研成果评比一等奖。
> 用法：对照 `02-研究报告写作框架.md` 的三层质量模型与六映射阅读——本文档按报告原结构重排，每节后附【亮点批注】。

## 报告结构总览

| 报告板块 | 对应六映射 | 范文对应章节 |
|---|---|---|
| 问题的提出 | 问题 | 一、研究缘由 |
| 理性思辨 | 归因 | 一（二）从核心经验的思考 + 三（一）概念界定 |
| 研究历程 | 实施（时间线） | 二、研究历程 |
| 内容策略 | 假设+实施 | 三、成果内容（理论建构+实践操作"四有"） |
| 成效分析 | 分析、结论 | 四、研究成效 |

## 一、研究缘由（问题的提出）

**结构**：政策依据（《3—6岁儿童学习与发展指南》对体育活动的定位）→（一）区域现状四大问题 →（二）核心经验介入的三点思考。

**现状四问题**（转述）：
1. 目标取向——定位极左极右（或只谈情感不敢碰技能，或曲解《指南》过度强调动作规范）；
2. 内容体系——选择随意无序（教材未按系统编制，教师"东选一节、西挑一节"，未遵循动作技能形成规律）；
3. 活动形式——方法无所适从（或形式单一以讲授为主，或 20 分钟内不停变换场景道具）；
4. 评价总结——缺乏科学指导（不知评什么、不知怎么评、不知谁来评）。

**核心经验介入的思考**（三点）：核心经验满足《指南》推进的现实需要（在《指南》与教学实践之间搭桥）；填补教师学科知识与教学方法的不足（儿童学习轨迹/易错点/个体差异三类知识）；与"四有"设计链接——"从极左极右的目标转向目标有依、从随意无序的内容体系转向内容有序、从无所适从的活动形式转向形式有玩、从缺乏指导的评价转向评价有维"（原书 p239）。

【亮点批注】
- **问题提出的针对性**：四个问题各一句话命名（取向/体系/形式/评价），每个都有课堂里的具体表现，一看便知针对什么——对应核心要素"逻辑的思考"第 1 条。
- **问题→成果的暗线**：四个问题与后文"四有"策略一一对应，读者在第一节就已看见报告的逻辑闭环。
- 政策文件引用（《指南》）与理论著作（《人类动作发展概论》）均规范注明出处。

## 二、研究历程

三阶段（转述）：
- **散点研究阶段**（2012.8—2016.8）：零星研讨+特色园自我研究，有论文发表与省级获奖，"点上成绩斐然，但是区域面上的体育教学状态不均衡"；
- **全面推进阶段**（2016.8—2018.8）：组建教研员、科研员、特级教师、骨干园长构成的核心团队，"以点带面、以小入手，以'四有'设计为抓手"；
- **已知未知阶段**（2018.8 后）：面向幼小衔接继续深化，"继续打开已知的未知篇章"。

【亮点批注】
- 历程不是流水账，每阶段一句话点出"做了什么+形成什么状态+留下什么新需求"，阶段之间是递进的研究逻辑而非时间罗列。
- 团队构成（教研员+科研员+特级教师+骨干园长）本身就是"研究味"的证据。

## 三、成果内容

### （一）理论建构

1. **实施理念**：坚持幼儿立场，立足动作核心经验设定目标、内容与游戏化路径；"增强每个幼儿的体质……没有统一的达标要求"（原书 p241）。
2. **概念界定**：依次界定"幼儿园体育活动（户外/早操/集体教学三种基本形式）→ 幼儿体育集体教学活动 → 动作核心经验（走、跑、跳、踢、投、滚爬六类）→ '四有'设计与实施研究"四个概念，层层嵌套。
3. **顶层设计**：一张扇形框架图（原书图27）——圆心"四有"设计实施，四等分为目标有依（总/单元/分层目标）、内容有序（三条途径/两种指向）、形式有玩（四种活动方式/游戏策略）、评价有维（多维时机/多维主体），动作核心经验贯穿四维。

【亮点批注】
- **理论思辨的严谨性**：概念界定从大到小四层递进，每一层都直接服务后文操作——"四有"定义里就预埋了全部策略维度。
- 顶层设计"一图统全篇"：一张图让读者 30 秒把握整个成果框架（结构图三型之"板块结构图"的标杆用法）。

### （二）实践操作（"四有"策略）

**1. 目标有依**——将动作核心经验提炼为教学目标，三级落地：核心总目标定位 → 六类动作的单元目标（按 3—4/4—5/5—6 岁分龄）→ 分层目标具体描述（配"教学内容—适用学期—核心动作—分层目标"表格，如"小球跳起来/沙包跳起来/玩偶跳起来"同动作进阶）。

**2. 内容有序**——三条途径（筛选现有教材 / 改进园本自创活动 / 创编新活动）+ 两种指向（按基本动作维度重新归类；按年龄特点由易到难排序，如"滚爬单元"分级表）。

**3. 形式有玩**——构建四种活动方式，各配流程图与案例：
- 方式一：动作发展导向（准备→主体性游戏[单一动作]→综合性游戏[组合动作]→放松）；案例：小班《从高处向下跳》单一到组合进阶；
- 方式二：运动智能导向（平衡/协调/速度等单一到多智能组合）；案例：大班《小篮球：运球》；
- 方式三：探究活动导向（自主探索→交流分享→提升探索→延伸）；案例：大班《快乐伙伴向前进》，由"两人三足"重规则优化为"合作走"重探索，动作约束由松到紧、人数由少到多（原书图31）；
- 方式四：社会性规范导向——"不适宜组织专门的教学活动，而应渗透在上述三个活动方式中的任何环节，做到无声胜有声"（原书 p242）。
- 四种方式的整合：三圆交集关系图（原书图32），分出单一型/复合型/综合型三种课型，"更希望在教学中多呈现出复合型与综合型"。
- 游戏策略两组：基于内在本质（动作序列层次性、多动作组合性、多维度扩展性三种变式设计）；基于外显形式（主题情节引入、道具器材植入、竞赛游戏加入）。

**4. 评价有维**——多维时机（评价存在于动作习得全过程，而非只评结果；配"单一结果评价 vs 多元过程评价"对照表）+ 多维主体（教师十种评价策略、幼儿互评六种策略、幼儿自评五种策略、家长三种策略，各列具体名目）。

【亮点批注】
- **研究策略的条理性**（核心要素）：每条策略都是"命名（四字口诀）→ 操作要点 → 流程图/表格 → 课堂案例"的固定句式，可归纳、可重复、可直接借鉴——这正是"为别人可借鉴"的三特点落地。
- **具体与抽象的和谐**（增色要素）：每条策略都配真实教学案例（《从高处向下跳》《快乐伙伴向前进》），抽象模式立刻可感。
- 图表密度高但各有分工：框架图统全篇、流程图讲操作、表格做归类、关系图讲整合——"适当+适度"的正面示范。
- 方式四"渗透而非专门开课"是实践层面的真创新：敢于把一种"维度"处理为"不独立实施"，比硬凑四节平行课更符合教育规律。

## 四、研究成效

四条成效（转述）：
1. **厘清六类动作发展要素及必要性**（理论成果，配"六大动作发展要素表"：身体移动四类+器械操控两类，并论证动作发展对幼儿全面发展的基石作用）；
2. **"四有"设计推动区域体育教学改革见效**（配 2016.8—2018.8 成果汇总统计表：子课题立项 29 项、论文获奖 33 篇、发表 5 篇、经验交流 14 次、教学展示 47 节、运动成绩 37 次、省级荣誉称号 3 项，均分省/市/区三级统计）；
3. **幼儿运动能力显著提高**（对象维度，配三张图：控制与平衡能力折线图、身体移动能力条形图、器械操控能力条形图，分述控制平衡/移动/器械操控三方面发展）；
4. **形成区域"科—研—训"整合式推进模式**（策略维度，配同心圆路径图：科研领航铺路→核心团队、教研课例突破→骨干教师、师训重组成蝶→全体教师；三条路径各有机制：月月研讨+子团队"大团抱小团"、区内联动+区外联动、90 学分班+短期班）。结尾一句区域教风变化："从最初回避开展体育教学，到如今人人参与教学研究"（原书 p248）。

【亮点批注】
- **成效三维度齐全且各得其所**：策略维度（"四有"体系+"科—研—训"模式）、对象维度（幼儿三方面能力数据）、区域/研究者维度（教风变化，侧面补充）。
- 成效 2 用一张多级统计表呈现区域影响力——比罗列文字高效得多（统计表用法示范）。
- 成效 4 把"模式"画成同心圆路径图，"三类研究活动对应三类教师群体"一句话说清机制（综合关系图示范）。
- ⚠ **反面提醒**：原书图33—35 的图例（研究前/研究后）与正文结论方向存在标注疑点（转换稿已照原图直录并标"存疑"）。你的报告必须逐项核对图例与结论方向一致——图表会替你说错话。

## 总评：这份一等奖报告为什么"出彩"

| 三层质量模型 | 范文表现 |
|---|---|
| 基本要素 | 问题—归因—假设—实施—分析—结论全程覆盖，六映射无缺漏 |
| 核心要素 | 两年区域实践支撑（实践体验）；四问题↔四策略↔四成效的闭环逻辑（逻辑思考）；"四有"命名、方式四渗透设计、"科—研—训"模式（创新元素） |
| 增色要素 | 四字口诀式语言；每策略配案例；框架图/流程图/表格/路径图各司其职 |

可迁移的三条写作动作：
1. 先造"问题↔策略↔成效"的对照表，再动笔——闭环是设计出来的；
2. 每条策略用"口诀命名+要点+图+案例"的固定句式写；
3. 一张顶层设计图放在理论建构末尾，统摄全篇。
