# 09 · 文献研究报告完整示例：跨领域 PBL 学习研究述评

> 范文来源：《真问题驱动：跨领域的PBL学习研究述评》（马晶，原书 p177—186），获区教育科学研究"自主微型研究"成果一等奖。来源标签：【浙江嘉兴·九年一贯制学校·跨学科主题】。本文件做结构化呈现并加批注，学习其**综述结构与"述而评之"笔法**，PBL 内容本身不是重点。

## 一、范文骨架（先看结构，再看内容）

```
标题：真问题驱动：跨领域的PBL学习研究述评
摘要 + 关键词
一、问题缘起：源于学科分而学之，学生综合能力弱   ← 为什么做这个综述（真问题）
    附图：PBL 期刊数量分布图（2006—2018 分四时段，2015 年后爆发式增长）
二、PBL 相关综述，厘清源头                       ← 主体：五维度分述
   （一）PBL 概念界定        —— 各家定义罗列 → 关键词分析 → 本文的界定
   （二）PBL 教学模式的研究   —— 三种模式罗列 → 比较 → 表明认同哪一种、为什么
   （三）PBL 教学设计的研究   —— 三方面研究归纳 → 提炼出转化逻辑
   （四）PBL 问题与对策的研究 —— 教师/学生/学校三层问题归纳 → 综合判断
   （五）PBL 评价体系的研究   —— 四种评价方案分述 → 归纳评价原则
三、PBL 研究动向探讨                              ← 总评：四条深化方向
四、PBL 的实践思考                                ← 落点：教师/学生/家长/社会四层面
五、结语
```

## 二、关键段落与批注

### 1. 缘起：用数据立"为什么综述"

> 范文做法：先用一张"PBL 期刊数量分布图"（2006—2009 年 7 篇 → 2015—2018 年 201 篇）说明该主题近年爆发，再交代"本文从概念、教学模式、教学设计形式、问题与对策及评价等方面，综述已有研究"（原书 p178）。

**批注**：缘起回答两个为什么——为什么这个主题值得综述（增长数据+教学改革热点），为什么由我来做（我面临"分科教学导致综合能力弱"的真问题）。**数据化缘起**比"近年来 PBL 备受关注"的空话有力得多。

### 2. 概念界定维度：罗列之后必须有"本文的界定"

> 范文做法：先并列三位学者对 PBL 的不同界定，随后"通过关键词分析，可以发现聚焦在以下核心：基于问题的、基于项目的、基于案例的……所以本文在理解 PBL 时主要参考基于项目的项目式学习"，并归纳出共同要素（原书 p179—180）。

**批注**：这是"综而述之、述而评之"的标准操作——不是罗列完就结束，而是用关键词分析把分歧收敛为共识，再**明确本文采用的工作定义**。写综述最常犯的错就是"各家观点展览"，没有自己的收束。

### 3. 模式比较维度：比较之后要表态

> 范文做法：罗列三种 PBL 教学模式后，明确"本文比较认同……'七步学习法'……因为 PBL 强调以学习者为中心"，并给出认同理由（原书 p181）。

**批注**：综述不是中立陈列。比较—表态—给理由，这个三段式让每个维度都有作者的判断痕迹，这正是原书"有分评有总评"的要求。

### 4. 评价体系维度：分述编号化，归纳收尾

> 范文做法：把四种评价方案编为 1—4 分述（基于表现的评价、德尔菲法+层次分析法、反馈与辐射两维评价、成果交流式评价），随后一段归纳："评价要遵循发展性、主体性、过程性以及多元化的原则"（原书 p183—184）。

**批注**：多方案并列时用编号分述保持清爽，段末必须有一段"这些方案共同说明什么"的归纳——分述+归纳是综述段落的基本单元。

### 5. 动向探讨：总评要落到"研究空白"

> 范文做法：四条动向——PBL 与 STEAM 融合发展（含一个基于真实问题的融合案例设计）、研究分布不均（附核心期刊/CSCD/硕博论文分布图佐证"深度不足"）、实践案例较少、缺乏校际合作（原书 p184—186）。

**批注**：总评段同样用数据说话（成果分布图），且每条动向都是"现有研究的不足 → 可做的方向"——**综述的终点是找到自己研究的入口**。范文后续的"实践思考"四层面（教师/学生/家长/社会），就是把综述成果转化为自己课题的行动设想。

## 三、可迁移的结构化写作清单

写自己的文献综述时，对照此清单：

- [ ] 缘起有数据（文献增长/分布图），并说明"我要解决的真问题"；
- [ ] 检索交代清楚：关键词（含变体）、数据库、时间范围、文献量级；
- [ ] 主体按 3—5 个维度组织，每维度"罗列 → 比较/分析 → 我的判断"；
- [ ] 每个维度段末有归纳句；
- [ ] 总评指出研究空白与动向，最好有分布数据支撑；
- [ ] 落点明确：本综述为自己的课题找到了什么入口/操作点；
- [ ] 所有引用核实过原文（学术诚信红线，见 00-当代适配）。
