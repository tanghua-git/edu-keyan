# 05 · 叙事研究与个案研究：设计、操作与辨析

> 来源：原书问题26（p142，方法概述）、问题29（p158—168，设计与辨析）。叙事研究五环节（f41）在三重验证中未独立晋级，此处按用户要求**作为素材保留**，与个案研究合并呈现并做辨析。

## 一、一句话区分

- **叙事研究**：从**文本呈现方式**定义——以讲故事的方式表达对教育教学问题的认识，借故事展现问题解决的策略方法。
- **个案研究**：从**研究对象范围**定义——针对一个人、一件事或一个团队做有目的、有计划的研究，以发现规律、提炼规律。

两者常交织：个案研究的报告可以用叙事方式写；叙事研究的"事"往往就是某个个案。辨析见第四节。

## 二、教育叙事研究：设计与五环节

**前提区分**：教育叙事 ≠ 教育叙事研究。前者着眼故事的生动可读；后者是"以教育叙事的形式，研究教育教学问题……发现或形成教育教学经验"（问题29/原书 p159），因此**需要设计**。四大特征：真实故事为载体、经验分享为取向、实践反思为媒介、意义建构为目的。

**五环节操作**（f41，原书 p159—161）：

1. **聚焦问题**：辨明问题性质——特殊性还是一般性、过程性还是突发性；摸清问题源头与对象，想清解决的基本路径。
2. **过程设计**：叙事研究关注的多是特殊性、过程性问题，需长期干预，因此要有目的、有计划推进，主题延续、目标一致。
3. **实施研究**：按计划对研究对象实际干预或影响。
4. **资料收集**：与实施同步，及时记录行动过程与反思问题，收集印证成效的材料。
5. **撰写文本**：报告含缘起、发展、结局；"必须用明确的主题将复杂、流变的故事统摄在结构之中"（原书 p161），重细节描写以保真——**忌流水账**。

**核心心法**："讲故事"与"析原理"恰当融合——故事里必须蕴含对教育教学规律的发现与提炼，否则只是随笔。

### 案例：小学高段习作"班与班"互评探索

> 来源标签：【浙江嘉兴·小学·语文】出自区自主微型研究成果集（问题29/原书 p161—162）。迁移点是"四次活动构成故事线 + 每次活动配思考问题"的文本结构。

- **缘起**：传统习作评改方式单一；六年级学生已有评改能力，对隔壁班有兴趣。
- **故事线（四次活动）**：初次互评（混乱如"没有硝烟的战争"→ 思考：教师该采取哪些指导措施）→ 再次互评（强调"点赞"发现亮点 → 学生自觉借鉴同学习作中的好方法）→ 三次互评（学生当"小老师"一对一指导 → 出现高质量的同伴建议）→ 四次互评（成果展示与多奖项评比）。
- **结语析理**：班际互评激发育作兴趣，发挥了"师生"双方的主动性与创造性。
- **结构启示**：故事按时间线推进，但每个节点都有"问题—调整—新发现"的研究痕迹，最后落到对教学规律的提炼——这就是"讲故事+析原理"的融合样例。

## 三、教育个案研究：方案结构与代表性红线

**定位**：个案研究最大特色是"单个"——单个学生、教师、团队或事件。一线教师主要用于特殊学生、新手教师等个体的持续跟踪。质性研究中"个案研究方法居多，占 64.7%"（问题29引姚计海等统计，原书 p162）。

**方案结构四部分**（问题29/原书 p165）：研究对象与问题（背景说明）→ 研究目的与重点 → 研究的步骤、内容与方法（观察、访谈、测验等）→ 预期成果。制订完善方案是基础，执行中可适当调整，但必须严谨按方案推进并做好资料收集。

**代表性红线（原书立场，必须守）**：

> "个案研究最基本的特征是：具有典型性，不具有代表性"，个案"不是依照假设和变量来操作的，所以也不是总体的样本"，因此"个案研究的结论，更多的是获得一种启示或认同"（问题29/原书 p164—165）。

- 结论表述写"该生呈现……倾向"，不写"所有学生都……"；
- 要把个案发现推广为策略，须补大规模调查验证（原书 p142 亦提示"个案研究后有时可能要进行大规模的调查研究"）。

### 案例：基于知识地图的新手教师微培训个案研究

> 来源标签：【期刊论文·教师培训】马宁等《教师教育研究》2018(1)，原书 p165—166 转引。迁移点是"小样本+多工具"的严谨设计。

- **对象**：2 名新手教师（教龄 1 年、3 年各一人）。
- **设计**：个案研究为主，辅以访谈、观察；工具含学习记录表、概念图评价指标体系、定量分析工具。
- **结构**：问题提出 → 相关研究 → 研究设计 → 数据获取与分析（学习路径分析、概念图评价、访谈分析）→ 讨论与结论（知识地图有助于定位知识点、减少迷航、提升知识结构化程度）。
- **启示**：个案研究不是"写个故事"，小样本更要靠多工具、多来源数据互证来立论；结论表述限定在个案范围之内。

## 四、叙事 vs 个案：联系与区别辨析（原书问题29 核心）

| 维度 | 叙事研究 | 个案研究 |
|---|---|---|
| 定义视角 | 文本呈现方式（讲故事） | 研究对象范围（单个对象） |
| 关注重点 | 故事背后的教育道理与意义建构 | 对象变化规律的发现与提炼 |
| 方案要求 | 五环节设计，重过程记录 | 四部分方案，重方法与工具 |
| 典型产物 | 叙事研究报告（缘起—发展—结局） | 个案研究报告（含数据分析） |
| 常见误用 | 有故事无析理（变随笔） | 结论推广越界（变伪规律） |

**选用建议**：想研究"一个对象怎么变"——用个案研究的方法做，报告可借叙事方式呈现；想提炼"一段干预过程的经验并感染同行"——用叙事研究，但必须先聚焦问题、设计过程，不能写完随笔再贴"叙事研究"标签。
