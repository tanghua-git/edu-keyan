# 04 · 课例研究两范式：个体前测驱动 / 群体多轮跟进

> 来源：原书问题28（p153—164）。两范式通过三重验证（v-fa-03）：个体用"基于前测四环节"，群体用"指向共生多轮行为跟进"。

## 一、先分清：课例研究 ≠ 听评课

课例研究"是以一节课为案例进行分析研究的过程"，实质是解决"教什么""怎么教""教得怎样"三个基本问题（问题28/原书 p153）。它与普通听评课的区别：有研究主题、有数据或观察工具支撑、有分析提炼出口。崔允漷团队的"五部分结构"（背景、课前会议、课中观察、课后会议、附件）是通用工作程序参考。

**范式选择判据（一句话）：一个人做，用前测四环节；一个组做，用多轮行为跟进。**

## 二、范式一：基于前测的课例研究（适合个体）

**四环节结构**：学情调查 → 教学设计 → 教学实施 → 效果分析（原书 p154 图17）。

各环节的研究动作：

1. **学情调查**：解读教学内容（基础）→ 设计前测问题（关键，覆盖知识理解、技能掌握、学习方式/活动经验）→ 组织前测 → 分析数据。
2. **教学设计**：依据前测数据重定学习目标 → 选策略、设计学习活动。
3. **教学实施**：调控学习进程、利用生成资源、适度调整活动。
4. **效果分析**：后测或作业诊断效果 → 反思策略 → **提炼一般规律**（从"一节课"上升到"一类课"）。

原书定位："材料设计与研究实施上相对简便……比较适合教师个体实践"（问题28/原书 p157）。

### 案例：分数乘分数——运算法则需要"立体"建构

> 来源标签：【浙江嘉兴·小学·数学，作者本人实践】原书 p154—157，论文发表于《小学教学设计（数学版）》2012(23)。迁移点是"前测暴露'形式模仿≠意义理解'"的分析路径，不是分数教学本身。

- **前测**：3 道分数乘分数计算题。结果：两班 50% 和 53.8% 的学生"会"算；但 13.5% 结果对方法错；访谈发现**没有一位学生能解释算理**，方法来自家长或奥数班。
- **关键判断**：学生"会"的只是形式模仿，未达意义理解——这直接改写教学目标定位。
- **设计**：三个层次活动——情境中分数意义解读（唤起经验）→ 探究算式意义（沟通"运算意义"与"运算程序"）→ 算法梳理（凸显算法与算理相互依存）。
- **提炼**："算法是显性存在、可以模仿的；算理则是存在于算法背后的依据，具有隐蔽性，却有着相当丰富的探究价值"（原书 p157）——从一节课提炼出"算法教学不能止于算法"的一类课规律。

## 三、范式二：指向共生的课例研究（适合群体/备课组）

**多轮行为跟进结构**：确定主题 → 设计预案 → 课堂实践 → 分析诊断 → 反思经验；内嵌循环"课堂实践 → 分析诊断 → 达成共识 → 改进设计 → 再实践"（原书 p156 图18）。

操作要点：
- 主题先行，聚焦一个课堂矛盾点；
- 预案来自"个体设计 + 分享研讨"；
- 实践者可指定可抽签；每轮实践后围绕主题诊断、找原因、提策略、达共识，再设计再实践；
- 在"多次改进、多次实践"中体悟策略、内化经验。

原书定位：突出磨课研讨，"需要团队的力量、群体的智慧……可以作为校本研修的基本方式"（问题28/原书 p157）。

### 案例："三次备课，两轮打磨"框架

> 来源标签：【浙江嘉兴·中小学·多学科通用】出自区自主微型研究成果集（问题28/原书 p157）。迁移点是备课—上课—反思的节奏结构。

- **三次备课**：基于个人经验的起始性备课 → 教研组同伴互助的协同备课 → 课后实践反思性备课。
- **两轮打磨**：围绕三次备课和两次上课，跟进集体备课、分工观课、课后评议。
- **收获**：追踪研究并解决锁定的问题，"每个人都获得同伴互助和实践反思后的两次认识提升"。

## 四、误区

- ❌ 把公开课/听评课直接当课例研究——没有前测、没有围绕主题的分析诊断，只是教研活动。
- ❌ 群体范式做成"一人上课众人夸"——缺"达成共识→改进设计→再实践"的跟进闭环。
- ❌ 做完不提炼——效果分析环节必须产出"一类课"层面的规律，否则止步于一节课的经验。
