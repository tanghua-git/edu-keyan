# 02 · 行动研究：一线教师的总范式

> 来源：原书问题25（原书 p137—146）、问题26（p142）。案例 c43 为转述陈向明书中的个案，标注来源。

## 一、定位：为什么是总范式

一线教师的研究"是一种主要以实践问题为取向的研究"（问题25/原书 p137），其基本形态是行动研究：教师既是实践者也是研究者，"行动中做研究，研究中有行动"，走的是"实践—反思—改进—再实践"的循环。

关键认知：行动研究是**总范式**，不是"不需要方法的自由发挥"。在这个范式之下，调查、课例、个案、实验、文献等具体方法按需嵌入，以体现研究的科学性与实证性（问题26）。

## 二、走出误区：行动研究 ≠ 随意做

原书第四章首要纠正的误区：

> 许多一线教师"认为……在制订课题研究的总体方案时无须深入思考、周密计划；在研究实践中，有时可以完全放弃原有研究计划，重新规划研究进程"（问题25/原书 p137）。

纠正：行动研究的进程**会随情境调整**，但整个过程"仍然是有计划、有思路、有方法、有提炼的"（问题25/原书 p137—138）。换方向 ≠ 放弃计划——调整的是路径与具体目标，研究目的不能丢。

**预警信号**（出现即说明已滑入误区）：
- 没有总体方案就开做；
- 研究过程随性转向，说不出"现在的做法与原目的什么关系"；
- 做完只有"我做了很多事"，没有任何结论与策略提炼。

## 三、四要点（v-fa-01）

**1. 研究随情境，思路须明确**
情境是根基——问题产生于课堂实践、方法尝试落于课堂实践。但随情境不等于没主题：研究主题、问题归因分析必须清晰。

**2. 过程重实践，方法须科学**
实践是获取第一手资料的基本形式，但观察、实验、测量等科学方法同样要用。比如调整一种教学组织方式后，要观察并收集数据判断调整效度，而非凭"感觉不错"。

**3. 目标可调整，目的不改变**
随情境变化可以调整具体研究目标与路径，但要解决的"真问题"（研究目的）保持不变。这是行动研究的张力处理原则，也是回答"中途发现原假设不对能不能换方向"的判据：**能换路径，不能换目的**，且须补做提炼。

**4. 研究出结论，策略有提炼**
行动研究不只是"改进了自己的教学"，还要得出结论、提炼可供同伴采用的操作策略。没有提炼的行动研究只完成了一半。

## 四、案例：L 老师"生问生答"行动研究

> 来源标签：【转述案例·高中·英语】原书转引自陈向明《在行动中学作质的研究》（问题25）。价值在于完整演示四要点，学科细节（英语情境教学）不迁移，迁移的是研究逻辑。

**过程梗概**（原书 p138—140 压缩）：
1. **起点**：L 老师的课题是"情境教学中如何发挥学生的主体性"，受一篇论文启发，尝试"生问生答"教学方式。首课感觉良好：学生提问多、积极性高。
2. **第一轮反思**：发现学生提问多停留在理解课文层面，思维含量不足 → 调整：要求学生提需归纳概括的问题。
3. **第二轮反思**：自由交流导致课堂吵闹、缺少倾听 → 再调整："先分组问答，再全班问答"，课堂秩序改善。
4. **目的锚定**：整个过程中"借助情境教学发挥学生主体性"的目的未变，变化的是对情境教学目标定位的理解与具体做法。
5. **产出**：提炼出"生问生答是体现学习主体的有效方式""提问质量需要思维层面的要求""有效组织需要教学管理跟进"等结论，及"适度引导策略""先分后合策略"等操作策略。

**对照四要点读案例**：情境真实（要点1）✓；用观察判断调整效度（要点2）✓；目标定位调整而目的不变（要点3）✓；有结论有策略（要点4）✓。这是一个"想好了做研究"的标准样例——不是一上来全想清楚，而是**每一步都有反思锚点，最后有提炼出口**。

## 五、给你的行动自检清单

- [ ] 我的课题有书面总体方案（哪怕简明），不是"边做边想"；
- [ ] 每次调整做法时，能写清"为什么调、目的如何不变"；
- [ ] 过程里有观察/测量/数据，不是全凭感觉；
- [ ] 阶段性地提炼出"结论 + 可操作策略"，不是只有活动记录。
