# 01 · 方法选择决策表

> 依据原书问题26—32 整理。一线教师以行动研究为总范式，本表用于在总范式下选择**具体嵌入的方法**。

## 一、速查表：研究目的/对象/场景 × 八种方法

| 你这个环节要干什么 | 首选方法 | 备选/辅助 | 不适用信号（看到这些词就别选） |
|---|---|---|---|
| 把"感觉学生有问题"变成可聚焦的研究点 | 调查研究（问卷/访谈） | 教学微调查 | 已有明确假设要验证因果 → 用实验研究 |
| 印证"问题在我这个班/校是否真实存在" | 调查研究（测量/问卷） | 微调查 | 想得出普遍规律但样本只有一个班 → 结论降格为"本校情况" |
| 证明课题策略"有效"（前后变化） | 调查研究（前后测采集数据） | 准实验（有对照班时） | 没有基线数据就宣称"显著提升" |
| 改进一节课/一个知识点的教学 | 教学微调查 或 课例研究（个体：前测四环节） | — | 只想听评课、不愿做前测后测 → 那是教研活动不是研究 |
| 备课组/教研组共同打磨一节课 | 课例研究（群体：多轮行为跟进） | — | 一个人单干却套用群体范式 |
| 跟踪一个特殊学生/一位新手教师的成长变化 | 个案研究 | 叙事研究（呈现方式） | 想拿结论推广到"所有学生" → 个案不具代表性（红线） |
| 记录一段干预过程、提炼经验并感染同行 | 叙事研究 | 个案研究（对象维度） | 只有故事没有"析原理" → 是教育叙事，不是叙事研究 |
| 确证"某方法导致某效果"的因果关系 | 实验研究（确认性实验/准实验） | — | 无法设对照、控不了变量 → 降格为准实验或改用调查 |
| 选题前了解领域全貌、写研究综述 | 文献研究（围绕主题） | 泛在文献研究 | 想用 AI 总结的文献观点不核实原文 → 学术诚信红线 |
| 研究一节课的教学演变史 | 文献研究（就一节课） | 课例研究 | — |

## 二、三个关键判断轴

**轴 1：目的类型**
- 描述现状/发现问题 → 调查、微调查
- 改进实践/提炼策略 → 行动研究 + 课例研究/叙事
- 理解个体 → 个案研究
- 确证因果 → 实验研究
- 站在前人肩上 → 文献研究

原书提醒："有些研究只是探索性的，为的是积累经验、提出假设；有些只需作相关性研究或描述性研究……并不是所有的研究都需要做实验"（问题26/原书 p142）。

**轴 2：组织形式**
- 个体单干 → 基于前测的课例研究、微调查、个案研究、叙事研究、小规模调查
- 备课组/课题组群体 → 指向共生的课例研究、分工式大调查、准实验（跨班）

**轴 3：资源条件**
- 有平行班可作对照 → 可做准实验
- 只有一个班 → 微调查前后测、课例研究
- 有跨校团队 → 大样本调查（注意统一工具与基线）

## 三、选择流程（四步）

1. **写目的**：一句话写清本环节要"发现/印证/采集/改进/跟踪/验因果/综述"中的哪一个。
2. **查表定位**：在上表找到对应行，锁定首选方法；读"不适用信号"自检。
3. **定组合**：一个课题通常是"行动研究为底色 + 1—2 种具体方法嵌入"，例如"行动研究 + 课前课中课后三次微调查"，或"行动研究 + 个案研究 + 末段一次印证性调查"。不要堆叠超过 3 种方法。
4. **落到工具**：为每种选定方法确定具体工具（问卷/访谈提纲/前测卷/观察量表/测试题），工具未定，方法不算选定。

## 四、常见错配警示

- ❌ 为了"显得科学"硬加实验 → 原书反面立场：只需相关/描述时硬上因果是误用（问题26/原书 p142）。
- ❌ 用个案结论下全称判断 → 违反"典型但不具代表性"红线（问题29）。
- ❌ 把"行动研究"当成不做任何设计的借口 → 见 02-行动研究的误区节。
- ❌ 大问卷发完只用来交差 → 调查的常态是"嵌入式小调查"，不是宏大工程（问题27，v-fa-02 洞见）。
