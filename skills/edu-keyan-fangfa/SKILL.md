# 教育科研方法的应用（edu-keyan-fangfa）

> 方法论单元源自费岭峰《怎么做课题研究——给教师的40个教育科研建议》第四章（问题25—32）及"文献研究"报告示例，经仓颉流水线三重验证。源书案例多为小学数学/幼教情境，使用时请平移到用户自己的学段学科。

## 何时使用（When）

用户**已经定了课题**（或正在做课题），面临以下任一问题：

- 不知道自己的课题该用哪种/哪几种研究方法；
- 想具体做某一方法（如发问卷、做课例、做个案跟踪、做前后测实验），要操作步骤与误区提醒；
- 被评审质疑"方法不科学""行动研究变成随意做"，需自纠；
- 想把课堂教学从"经验判断"升级为"实证判断"（微调查、前测驱动）。

**不适用**：课题还没定（→edu-keyan-xuanti）；要写的是方案文本中的"研究方法"段落（→edu-keyan-fangan）；问的是资料积累与研究活动组织（→edu-keyan-shishi）；问的是成果报告中成效如何表述（→edu-keyan-chengguo）。

## 八法速览（Overview）

一线教师以**行动研究为总范式**（"想好了做研究"），在行动研究的大框架下，按需嵌入以下具体方法：

| 方法 | 一句话定位 | 最适合的场景 |
|---|---|---|
| 行动研究 | 总范式：有计划地边做边改 | 几乎所有一线课题的底色 |
| 调查研究 | 用问卷/访谈/测量拿数据 | 发现与聚焦问题、印证假设、采集成效数据 |
| 课例研究 | 以一节课为案例研究课堂 | 围绕课堂教学的课题；个体用前测四环节、群体用多轮行为跟进 |
| 叙事研究 | 讲故事+析原理 | 记录一段干预/改进过程，提炼经验 |
| 个案研究 | 跟踪单个对象（人/团队/事件） | 特殊学生、新手教师等个体研究；结论只作启示不作推广 |
| 实验研究 | 控变量、验因果 | 需证明"某方法导致某效果"时；一线只做确认性实验与准实验 |
| 文献研究 | 站在前人肩膀上 | 选题、写综述、研究一节课的教学史 |
| 教学微调查 | 课前测—教学—课后测闭环 | 一节课的教学设计与效果诊断 |

详细的"研究目的 × 方法"速查与选择流程见 [references/01-方法选择决策表.md](references/01-方法选择决策表.md)。

## 执行步骤（Execution）

1. **明确研究目的与场景**
   用一句话回答：我这个环节要"发现/聚焦问题""印证假设""采集成效数据""改进一节课""跟踪一个对象"，还是"验证因果关系"？同时确认是**个体单干**还是**团队/备课组**，是否有对照班可用。
   完成标准：能写出"目的=……；组织形式=个体/群体；可用资源=……"三行备忘。

2. **查 01 决策表选法**
   打开 [references/01-方法选择决策表.md](references/01-方法选择决策表.md)，按目的与场景定位到 1—2 种候选方法，阅读"不适用信号"一栏排除错配。
   完成标准：选定主方法（必要时配辅助方法），并能说清"为什么是它、为什么不是另一个"。

3. **读对应方法文件**
   按选定方法读对应 reference（见下方加载指引），重点读"操作步骤"与"误区/红线"两节。
   完成标准：列出该方法在你课题中的具体动作清单（谁、何时、用什么工具、产出什么资料）。

4. **按步骤执行并留存过程证据**
   照该方法的步骤做，每一步留存可回溯的证据（问卷原件、前测数据、访谈记录、观察量表等）。执行中若情境变化，依行动研究"目标可调整、目的不改变"的原则调整。
   完成标准：每个方法动作都有对应的过程性资料归档；任何方向调整都记录了"为什么调、目的如何保持不变"。

5. **对照误区自检**
   完成后回到该 reference 的误区清单逐条自核（如：个案结论是否写成了全称判断？实验是否在没有对照的情况下断言了因果？调查数据是否真实采集？）。
   完成标准：逐条打勾，发现问题即修正表述或补做环节。

## 边界（Boundaries）

**三条红线（源自原书立场，必须守住）：**

1. **作者经验是建议而非定律。** 本书方法论是一位发达地区教研员的近30年经验归纳，不是普遍定律；不同省市申报口径、不同学校条件差异很大，引用时不得表述为"必须如此"。
2. **方法有效性的判断以用户实际情境为准。** 决策表给出的是适用域参考，最终"这个方法对我的课题合不合适"要由用户结合自己的对象、条件、时间判断；拿不准时优先小范围试做（如微调查），再放大。
3. **个案结论不具普遍代表性。** 原书明确立场："个案研究最基本的特征是：具有典型性，不具有代表性"，结论"更多的是获得一种启示或认同"（问题29/原书 p158—168）。单个/少数个案的发现不得推广为全称判断，要推广须补大规模调查。

**其他边界：**

- 实验研究一线只做确认性实验与准实验；只需相关或描述研究时，不要硬上因果断言（问题26、30）。
- 行动研究不是"无须计划、随时放弃计划"——这是原书第四章首要纠正的误区（问题25）。
- 调查数据、前后测数据必须真实采集，严禁编造或用 AI 生成"数据"（详见 00-当代适配的学术诚信红线）。
- 案例均标注来源标签（地区/学段/学科），小学数学案例的教法细节不要照搬到其他学段学科，要迁移的是**方法结构**而非具体教法。

## 失败模式与回退（Failure Modes）

> 选法前先扫一遍：遇到下列情形按对应分支处理，不要硬走正向流程。

| 编号 | 触发情形（If） | 回退动作（Then） |
|---|---|---|
| F1 | 用户未说明研究目的 | 先用「目的三问」定位：①要发现／聚焦问题，还是 ②印证假设／采集成效数据，还是 ③改进一节课／跟踪一个对象／验证因果？目的未定不选法 |
| F2 | 用户条件不具备所选方法（如无对照班却想做实验） | 降级：无对照班 → 行动研究＋前后测，**不作因果断言**；样本极少 → 个案／叙事研究。说明降级理由 |
| F3 | 用户方法堆叠过多（≥3 种） | 提示收敛到「1 主＋1—2 辅」，说明「方法服务于问题」，删去与本课题目的无关的方法 |
| F4 | 涉及问卷设计、数据分析、AI 辅助 | 先读 `references/00-当代适配.md`；强调**数据必须真实采集**，**严禁**用 AI 生成「数据」或编造样本 |
| F5 | 用户想把个案／少数样本结论推广 | 明确提醒个案「具有典型性、不具有代表性」，结论只作启示；要推广须补作大样本调查后再推断 |
| F6 | 所需 `references/` 文件不存在或读取失败 | 降级用本 SKILL.md 内嵌「八法速览」作答，说明「完整步骤与误区需补读 reference」，不假装读过 |
| F7 | 用户问题属方案段落／过程实施／成效呈现／选题（越界） | 分别转 `edu-keyan-fangan`／`shishi`／`chengguo`／`xuanti`，不代做 |
| F8 | 用户只问一个纯术语（如「什么是准实验研究」） | 直接给术语解释与边界，**不必**展开完整方法操作步骤；若需操作再进入正式选法流程 |

## 关键检查点（🔴 Checkpoints）

> 下列节点必须暂停并等待用户确认后再继续，不得自主连做。

- 🔴 **CHECKPOINT-1（目的确认）**：选法前先确认研究目的与组织形式（个体／群体、有无对照），确认后再查决策表。对应步骤 1。
- 🔴 **CHECKPOINT-2（方法选定确认）**：确定主方法后，先说明「为什么是它、为什么不是另一个」并请用户确认，再给操作步骤。对应步骤 2。
- 🔴 **CHECKPOINT-3（数据真实性门）**：涉及数据采集前，先确认数据将真实采集、严禁编造或 AI 生成。对应失败模式 F4。
- 🔴 **CHECKPOINT-4（越界终止）**：用户若要求本技能处理方案段落、过程实施、成效呈现或选题，转交对应技能，不代做。对应失败模式 F7。

## 反例与黑名单（Anti-patterns）

> 以下做法在本技能明确**不要做**；命中任一即视为执行偏差。

**A. 方法运用类**
- ❌ 未经目的定位就推荐方法（「大家都做问卷调查」）。
- ❌ 无对照班却做实验并断言因果——一线只能做确认性实验／准实验。
- ❌ 把「行动研究」当成「随便做、随时改」——它是有计划的研究（问题 25）。
- ❌ 把个案／少数样本结论写成全称判断——个案具有典型性、不具代表性。
- ❌ 方法堆叠（一次上四五种）——1 主＋1—2 辅足矣。

**B. 诚信与合规类（红线）**
- ❌ 用 AI 生成「数据」、编造样本或前后测结果——数据必须真实采集。
- ❌ 自编量表不做信效度就宣称「验证」。
- ❌ 把小学数学案例的具体教法照搬到其他学段学科——应迁移方法结构，而非教法细节。

**C. 越界类**
- ❌ 在本技能内写「研究方法」段落（属 fangan）、组织研究活动／积累资料（shishi）、呈现成效数据（chengguo）、做选题（xuanti）。

## 输出规范（Output Contract）

> 让研究方法的选择与运用稳定、可核、不跑偏。

1. **先定位目的、再选法**：首行给出研究目的与组织形式的判断，再查决策表选法。
2. **选定必给理由**：给出主方法（＋辅方法）并说明「为什么是它、为什么不是另一个」。
3. **步骤＋误区成对给**：给某方法的操作步骤时，同步给该方法的误区／红线清单，不只给正向。
4. **工具落地**：每个方法动作落实到具体工具（问卷／观察量表／前测卷／访谈提纲），工具未定不算选定。
5. **长度约束**：单次回答 ≤ 700 字；完整方法操作包可放宽至 1000 字。
6. **不做因果越界**：无对照、无前后测时不写「导致／显著提升」类因果表述。
