# 00-当代适配（2026 年视角的总览补丁）

> 原书成书约 2019 年，方法论内核至今成立，但热点锚点、工具环境、政策话语需要更新。本文件是路由技能的总览补丁；各阶段技能另有自己更细的 00-当代适配.md。

## 一、政策与热点锚点（替代书中的"核心素养/微课/电子书包"时代话语）

| 锚点 | 说明 | 对课题研究的用法 |
|---|---|---|
| 《"人工智能+教育"行动计划》（教育部、国家发展改革委、工业和信息化部、科技部、国家数据局，2026年4月） | 当前教育数字化最上位专项文件；含"提高教师智能素养与技能""利用人工智能赋能教师教学"等与一线教师直接相关的条目 | 选题的"应然"依据、课题提出的时代背景 |
| 《教育强国建设规划纲要（2024—2035年）》 | 教育领域中长期总纲 | 选题价值判断的政策导向维度 |
| 2022 版义务教育课程方案与课程标准 | 核心素养落地、跨学科主题学习、学业质量 | 学科类选题的课标依据 |
| 《国务院关于深入实施"人工智能+"行动的意见》 | "人工智能+"上位部署 | 人工智能教育类选题背景 |

**使用规则**：给用户做选题或写"课题提出"前，先确认其所处年份的最新政策；以上列表本身也会过期，必要时先联网核实文件名称与发文机关，不凭记忆引用。

## 二、AI 辅助教育科研工作流（全书流程的工具增强）

| 课题阶段 | AI 能帮什么 | 红线 |
|---|---|---|
| 选题 | 政策热点扫描、应然—实然矛盾头脑风暴、课题名称多方案生成与自检 | 选题判断由人做，AI 只提供候选 |
| 方案设计 | 文献脉络梳理、方案结构起草、逻辑对应关系检查 | **严禁编造文献**；引文必须核验原文 |
| 过程实施 | 研讨录音转写留痕、观察量表/问卷起草、过程资料数字化归档（知识库/多维表格） | 工具信效度人工把关；量表须课题组审定 |
| 方法运用 | 问卷与访谈提纲设计辅助、数据统计分析辅助 | **数据必须真实采集**，严禁 AI 生成调查数据 |
| 成果总结 | 图表生成、文字润色、答辩 PPT 结构化 | 观点、数据、案例必须源于真实研究；注意查重与引注规范 |

## 三、给使用者的总提醒

1. 本书作者样本偏浙江/小学数学/幼教，制度话语（教科规划/教研条线/微型课题分类）以嘉兴为样本——迁移到其他省份、学段、学科时，**迁移方法结构，不迁移制度细节**。
2. 书中"电子档案库四优势"写于 2019 年，今天的过程资料管理应直接使用云文档/知识库/多维表格，但"归类—编码—总结"三个动作不变。
3. 原书 p251 有三张数据图图例与正文结论方向相反（转换稿已标 `⚠ 存疑`）——引用该处图表数据时以正文文字结论为准。
