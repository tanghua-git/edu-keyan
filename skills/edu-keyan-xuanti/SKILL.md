# 教育科研选题与课题命名（edu-keyan-xuanti）

> 本技能蒸馏自费岭峰《怎么做课题研究——给教师的40个教育科研建议》第一章（问题1—8），
> 经仓颉流水线三重验证（V1跨域/V2预测力/V3独特性），并补入用户捞回的 2 条单元
> （"小题大做"原则 p13、"微型课题三要求" f08）。方法论单元编号沿用验证稿 X01—X06，
> 另以 p13 / f08 标注两条捞回项。

## 何时用（I）

你手里可能有一颗"想做研究"的心，但卡在三类问题上：
1. **找不到题**——日常工作里全是琐事，提炼不出值得研究的课题；
2. **有题无假设**——有问题、有困惑，但把"问题"直接当"课题"报上去，被说缺假设、不聚焦；
3. **有名无焦点**——方向想好了，课题名称却起得太大太空，评审一句"研究什么、怎样研究没讲清"就打回。

本技能把"零散的问题"变成"可操作、可申报、可聚焦"的选题与名称，覆盖从价值判断到落笔命名的完整链路。
它只解决"选什么、怎么聚焦、叫什么名"，**不负责**写研究方案、文献综述、课题提出/选题缘由论证段落。

## 核心方法论骨架（8 单元一页纸导航）

| 单元 | 解决什么 | 关键动作 |
|------|----------|----------|
| **X01 选题价值两维度** | 这个题值不值得做 | 找"应然—实然"矛盾；看"整体—局部"关联 |
| **X02 问题→课题四步** | 问题怎么变成课题 | 专业内涵 → 价值判断 → 可行性聚焦 → 逻辑细化 |
| **X03 选题四来源** | 从哪片土壤长题 | 自身实践三层面 / 改革热点三方式 / 经典理论两层面 / 他人经验四方式 |
| **X04 已有成果深化** | 有前期基础怎么再立题 | 形而上（理论建构）/ 形而下（实践路径） |
| **X05 热点双陷阱** | 防止"假大空 / 无新意" | 热点题"创新易做实难"；实践题"做实易创新难" |
| **X06 课题名称设计** | 名称怎么起才规范 | 常规三结构 + 创新三结构；三要求；三毛病自检 |

| **f08 微型课题三要求** | 微型题怎么有新意 | 亮特色 / 显个性 / 蹭热点 |

## 执行步骤（E）

**步骤 1 · 诊断用户阶段**
- 动作：判断用户处于「无题 / 有题但无假设 / 有方向但无名」哪一类，并确认其学段学科、是否已有前期课题。
- 完成标准：能明确说出用户类型，并据此决定从 X01/X03 还是 X06 切入。

**步骤 2 · 价值判断（对应 X01、X02 一二步）**
- 动作：用"应然—实然"矛盾或"整体—局部"关联，论证该问题为何值得研究；做内部/外部价值研判，剔除违背育人导向的题。
- 完成标准：用户能用自己的话写出本课题的"应然—实然"落差（或整体—局部切入点），且通过价值红线（非应试技巧、非机械训练类）。

**步骤 3 · 来源挖掘（对应 X03、X04）**
- 动作：从四来源（自身实践 / 改革热点 / 经典理论 / 他人经验）中锁定最贴合的来源，套用对应子方法；有前期基础者走 X04 深化路径。
- 完成标准：用户至少锁定 1 个来源，并写出具体的挖掘方式（如"联想迁移：把 A 学科方法移到 B 学科"）。

**步骤 4 · 聚焦（对应 X02 三四步、p13）**
- 动作：用可行性三条件（客观/主观/时机）收敛切口，从小处着手、适度聚焦到单一策略或单一环节。
- 完成标准：课题切口收敛到"一条策略 / 一个环节"，可用一句话说清研究点，不再罗列多个并列内容。

**步骤 5 · 命名（对应 X06、f08）**
- 动作：按 `references/03-课题名称句式库.md` 选结构产出 1—2 个名称；微型题叠加 f08 三要求。
- 完成标准：产出名称满足"三要求"（概念准确 / 变量逻辑清 / 有特色），且通过"三毛病"自检。

**步骤 6 · 自检（对应 04 清单、X05）**
- 动作：逐项勾 `references/04-选题自检清单.md`，重点过"热点双陷阱"与"微型课题三要求"预警。
- 完成标准：清单无红线项；若有热点题，已落实校本/班本抓手，无"为课题而做课题"信号。

## 边界（B）

① **经验不是定律**：本书方法论是作者近 30 年一线科研的经验归纳，是"建议"不是"定律"，
   不可奉为唯一标准；不同区域、学段、学科应结合实际调整。
② **热点须当下重扫**：书中热点锚点为 2018—2019（微课、电子书包、STEM、"区块链+"等），
   热点判断必须以当下政策与教学实践重新扫描——使用前先读 `references/00-当代适配.md`，
   严禁直接照搬书中过期案例当"热点"。
③ **口径以本地为准**：课题分类、申报层级与评审口径以本地科研管理部门最新文件为准，
   本书以浙江（尤其嘉兴）样本为主，仅供参考，不替代本地制度。
