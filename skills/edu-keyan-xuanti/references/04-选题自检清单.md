# 04-选题自检清单

> 用途：选题与命名完成后逐项勾选。任一红线项未过，回到对应 references 文件返工。
> 覆盖：价值 / 可行性 / 聚焦度 / 命名 + 微型课题三要求 + 热点双陷阱预警。

---

## A. 价值维度（对应 X01、X02 第二步）

- [ ] **A1 应然—实然落差**：能写出本课题"应该的样子"与"实际的样子"之间的具体矛盾。
- [ ] **A2 整体—局部切入点**：若用整体视角，已落到可操作的局部抓手（非空泛大词）。
- [ ] **A3 内部价值**：对本学科/本职实践有较强指导作用，或有一定创新。
- [ ] **A4 外部价值**：方法策略可迁移、对其他内容/学科有借鉴意义。
- [ ] **A5 不违背育人导向**：❌ 红线——若指向应试技巧、机械训练、与核心素养/立德树人冲突，直接判否（ce03）。

## B. 可行性维度（对应 X02 第三步）

- [ ] **B1 客观条件**：资料、时间、设备/技术、经费、人力基本具备。
- [ ] **B2 主观条件**：自身认识水平、知识能力、经验专长能支撑该研究。
- [ ] **B3 时机**：对该问题的思考积累已到可解决的节点。
- [ ] **B4 能落地**：不依赖"另外开一门课/活动"才能做（脱离日常教学即预警，ce01）。

## C. 聚焦度维度（对应 X02 三四步、p13）

- [ ] **C1 小处着手**：切口收敛到单一策略或单一环节，未铺开多个并列内容。
- [ ] **C2 一句话说清**：能用一句话讲清"研究什么、怎样研究"，无歧义。
- [ ] **C3 问题已转课题**：名称/设想里含"假设=待验证的解决方法"，非原样陈述问题（ce02）。
- [ ] **C4 逻辑可分解**：大问题已分解为可研究的子问题（核心概念类 + 策略路径类）。

## D. 命名维度（对应 X06、f08、03 文件）

- [ ] **D1 概念准确**：关键词含义清晰、无生造词。
- [ ] **D2 变量逻辑清**：自变量（措施）与因变量（变化）关系可辨。
- [ ] **D3 有特色/创新点**：能看出区别于他人的地方。
- [ ] **D4 第一时间讲清**：题名已把"研究什么+怎样研究"讲清，创新不淹没表意。
- [ ] **D5 三毛病排查**：❌ 红线——无关键词堆砌（ce07）、无对象不清（ce08）、无逻辑不清（ce09）。
- [ ] **D6 数概括慎用**：若用"数概括"结构（如三化两制），其内涵在题名外已先定义，否则回退常规结构（ce10/ce11）。

## E. 微型课题三要求（仅限微型/个人课题，对应 f08）

- [ ] **E1 亮特色**：名称或设想能看到内容创新点。
- [ ] **E2 显个性**：体现自身工作特质与研究特点（微观选题更易放大）。
- [ ] **E3 蹭热点**：若有热点元素，须是当下真热点（见 `00-当代适配.md`），且已校本化。

## F. 热点双陷阱预警（对应 X05）

- [ ] **F1 热点题防"创新易做实难"**：❌ 红线——若全堆热点词却说不清落点、计划空洞无校本/班本抓手，即 ce05"为课题而做课题"，须补具体抓手。
- [ ] **F2 实践题防"做实易创新难"**：若源于自身实践却只解决个人特有细节、无亮特色/显个性设计，即 ce06，须叠加 E1—E3 补新意。
- [ ] **F3 热点时效性**：书中热点（微课/电子书包/STEM/区块链+）已过期，今日起名不得直接照搬，须用 `00-当代适配.md` 重扫（AI+教育、教育强国纲要、新课标核心素养）。

- **仅一般项未过**：可带着清单找同伴/导师论证，边做边补。
